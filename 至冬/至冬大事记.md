> 注：本文档中的「TE」(Teyvat Era) 为提瓦特纪元缩写，以 TE 为统一纪年单位，记录[至冬](./至冬综述.md)国从远古至今 (TE 2030) 的重大历史事件。[至冬](./至冬综述.md)官修史书另以「纪」记年，起点系于妖精王庭旧事，与 TE 的换算尚无定论（详见[至冬综述](./至冬综述.md)）；本文统一采用 TE 纪年。[挪德卡莱](../挪德卡莱/挪德卡莱综述.md)相关历史事件以「（背景）」标注。

## 大事年表

| 年份 (TE) | 事件 |
|:---------:|:----|
| **远古** | 永冻之原为妖精领地，妖精组成神明王庭**苍星王廷**，掌握[月矩力](../挪德卡莱/挪德卡莱经济与产业概况.md)的原始运用，「妖精回廊」一类遗迹即出于此时 |
| **远古** | 南方海上**黄金国亥珀玻瑞亚**因触碰造物主领域遭寒天之钉毁灭 |
| **约 0** | **白沙皇莫诺马赫·雪奈茨尼伊**赢得北陆神位，成为第一任冰之执政；自终北故墟归来后赦恕人类为臣民，改国名为「至冬」，营建第一座城市**基捷**，其后迁都**至冬堡**；与兽怪联盟三度内战扫平群雄，以「冬之契约」组建[冬契军](./至冬军事概况.md) |
| **约 0** | 白沙皇立「不依赖天理也能独立存续」宏愿，开采**克什尼克晶矿**、修筑**克什尼克之炬**，「晶能立国、晶能归国家」两条国策自此发端 |
| **0** | **（背景） 魔神战争终结**，七神体系确立，白沙皇以冰之执政位列七神 |
| **0~1500** | **领主制时期**——波雅尔瓜分冻土带有限的可耕地与森林，农奴附着于土地，领主制运转一千五百年 |
| **1500** | **（背景） 坎瑞亚灾变**——白沙皇亲率[冬契军](./至冬军事概况.md)抗击深渊，力战而终，遗体葬于白冕宫；**同年 4 月安娜丝塔夏·费奥多罗夫娜·雪奈茨娜娅加冕**，是为冰之女皇，并于灾厄余波中亲率大军镇压黑暗之神切尔诺伯格 |
| **约 1500~1600** | **（背景）**至冬逐步向南扩张，完成对极北族群的整合，将[挪德卡莱](../挪德卡莱/挪德卡莱综述.md)纳入势力范围 |
| **1501** | 贝洛沃迪港的人类不堪妖精王公勒索，宣布自治 |
| **1502** | 女皇发兵平乱，强占卓沃戈列、伏尔霍凡与切纳雷卡三氏族领地，攫夺王公头衔改由非世袭官吏接管；3 月颁行《**帝国秩序改良诏书**》，令妖精王公放弃贵族头衔、离开至冬——皇室领地化由此开篇 |
| **1520** | **皇都评议会设立**，安娜·伊万诺夫娜出任初任议长；**[愚人众](./至冬政治概况.md)以「执行官」为核心组建**，成为横跨七国的情报与军事组织，暗中收集神之心 |
| **1600** | **[至冬科学院](./至冬经济概况.md)建立**，系统化研究坎瑞亚机关术与提瓦特元素反应 |
| **17 世纪初** | 内务部下辖的内卫武装整体移交[冬契军](./至冬军事概况.md)，内务部降格为内务总局 |
| **约 1800** | **工业化启动**——冻土带石油天然气大规模开发，重工业体系成型 |
| **1960** | **石油天然气管道网络**基本成型，辐射至冬全境及[挪德卡莱](../挪德卡莱/挪德卡莱综述.md) |
| **2001~2002** | **（背景）**愚人众执行官「女士」当众夺走[蒙德](../蒙德/蒙德综述.md)的风神之心 |
| **约 2005** | 至冬率先启动本币体系研究 |
| **约 2005** | **（背景）**[愚人众](./至冬政治概况.md)大规模进入[挪德卡莱](../挪德卡莱/挪德卡莱综述.md)，月矩力开采全面展开，开启「间接统治」时期 |
| **2008** | **至冬卢布率先发行**，至冬中央银行成立，拉开信用货币时代序幕 |
| **2015** | **（背景） 提瓦特财团联盟 (TFC) 成立**，至冬为创始成员国 |
| **2018** | **（背景）**《提瓦特自由贸易与关税协定》(TFTTA) 签署；《关于禁止元素武器扩散的框架协定》缔约，至冬附保留意见 |
| **2030** | **当前**——六颗神之心尽数到手；特大暴风雪引发能源危机，女皇直辖[国家航天局](./至冬航天概况.md)并启动探月工程，哥伦比娅复任[愚人众](./至冬政治概况.md)第三席 |

## 展望

| 纪年 | 事件 |
|:----|:----|
| **TE 2030 年及以后** | **探月工程**——[至冬](./至冬综述.md)成为提瓦特首个把月亮写入航天日程的国家，极地发射场与重型运载火箭已具备深空任务条件 |
| **未来数年** | **能源危机的消化**——特大暴风雪暴露集中供热体系与克什尼克晶矿供应链的脆弱性，[严冬计划](./至冬能源概况.md)的推进节奏成为评议会与建军派博弈的焦点 |
| **中长期** | **皇室领地化的延续**——自削藩开启的中央集权进程仍在延续，人类波雅尔与地方势力的空间持续收窄 |
