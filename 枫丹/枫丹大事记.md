> 注:本文档中的「TE」(Teyvat Era) 为提瓦特纪年缩写，以 TE 为统一纪年单位，记录[枫丹](./枫丹综述.md)从远古至今 (TE 2030) 的重大历史事件。[枫丹](./枫丹综述.md)重建共和国成立于 TE 1993 年，直接沿用提瓦特纪元纪年，无独立纪年系统。全局性背景事件以「（背景）」标注。

## 大事年表

| 年份 (TE) | 事件 |
|:---------:|:----|
| **远古（纪元前）** | **水仙十字结社的学术奠基**——阿兰·吉约丹在废弃机械工坊组装第一台荒芒能量激发装置雏形，雷内·佩特莉可在佩特里克镇记录水元素热交换的早期数据，雅各布·英戈德在厄里那斯古籍中追寻地脉能量知识；三人的探索为[枫丹](./枫丹综述.md)后世「双轨动力」路线奠定理论与工程根基 |
| **0** | **（背景） 魔神战争终结**——七神体系确立，[水神厄歌莉娅](./枫丹政治概况.md)获神之心，[枫丹](./枫丹综述.md)归入七神秩序 |
| **0~ 约 1500** | **厄歌莉娅时代的领主封建制**——土地分封效忠水神的大贵族：黎翡大区花田与葡萄园归迪昂家族等老牌贵族，苍晶大区矿区归工业贵族，[枫丹](./枫丹综述.md)廷周边商业用地由水神教廷直接管理；**梅洛彼得堡成为「放逐地」**——被流放者土地自动被贵族或教会没收，「土地作为刑罚工具」传统与水下地役权制度雏形形成 |
| **450** | **[枫丹](./枫丹综述.md)科学院事故**，引发[枫丹](./枫丹综述.md)社会对科技伦理的广泛辩论 |
| **约 1500** | **（背景） 坎瑞亚灾变**——大陆级灾难事件，波及提瓦特全境。[枫丹](./枫丹综述.md)亦受波及，水神厄歌莉娅在灾变中退位/去世，芙卡洛斯继位，厄歌莉娅时代结束 |
| **1750~1950** | **蒸汽与发条技术初步产业化**——水元素蒸汽技术从实验室走向工厂，发条机关开始应用于纺织与面粉加工；荒芒能量理论因技术难度过高停留在学术论文阶段，未能实现工程转化 |
| **1800** | **[枫丹](./枫丹综述.md)科学院达到巅峰**——水压能源与精密机关制造领先七国 |
| **1950~2005** | **荒芒技术的工程突破**——[枫丹](./枫丹综述.md)工程院成立，吉约丹家族后世的工程师对阿兰·吉约丹的原始设计进行关键性改良，荒芒核心的稳定性与寿命达到工业化标准；苍晶大区首批荒芒能量转换站建成，荒芒设备进入重工业领域 |
| **1965** | **废除义务兵役制**——施行全志愿兵役（募兵制），军人职业化程度高，[枫丹](./枫丹综述.md)国防体系转向精兵路线 |
| **1990~1993** | **旧秩序崩塌**——旧贵族伪造地契侵吞公共水域案引发社会抗议，旧议会解散 |
| **1993** | **[枫丹](./枫丹综述.md)重建共和国成立**，社会秩序恢复，精密机械出口超越传统水压能源产业 |
| **1993~1999** | **重建敕令与立宪**——水神[芙卡洛斯](./枫丹政治概况.md)颁布重建敕令，各方就新宪法框架展开六年拉锯，最终确立[贵族共和制](./枫丹政治概况.md) |
| **1998** | 荒芒实验室系列测试报告确立**临界尺寸效应**——荒芒能量腔体最小特征尺寸不得小于 2.4 米，荒芒设备「庞然大物」属性自此有实验定论 |
| **1999~2005** | **预言应验与灾后重生**——原始胎海之水淹没大片沿海地区（TE 2003 年灾情最烈），[枫丹](./枫丹综述.md)社会秩序经历剧烈变动；水灾扫清封建土地关系残留，国家在废墟之上掌握资源分配权 |
| **约 2005** | **土地法令颁布**——凡在洪水中失去地契的旧贵族领地，三年内未能提出有效证明者一律视为废弃地收归国有，纳入公共重建用地；重建用地管理局设立，国家主导的灾后重建全面铺开；发条机关与精密机械产业渡过危机，随重建复兴 |
| **2005~2012** | **（背景） 信用货币时代开启**——摩拉停铸引发的通缩效应向全大陆扩散，各国相继研究并发行主权信用货币并建立中央银行（2008 至冬卢布、2010 璃月元与[枫丹](./枫丹综述.md)科朗、2011 蒙德镑、2012 须弥卢比、稻妻圆、纳塔鎏金币） |
| **2005~2015** | **灾后重建与技术路线的历史性分野**——荒芒设备因不可移动性与本土依赖性，更多服务国家级重大工程（海底隧道、城市排水系统）；水元素蒸汽技术因小型化与出口潜力成为带动经济恢复的战略支点；「[枫丹](./枫丹综述.md)双轨铁律」在重建后的工程验证中明确定论 |
| **2010** | **（背景） [枫丹](./枫丹综述.md)科朗发行**，[枫丹](./枫丹综述.md)重建共和国中央金库成立 |
| **2016** | **枫丹—纳塔—须弥科技科研联盟 (FNS) 建立**——与[纳塔](../纳塔/纳塔综述.md)、[须弥](../须弥/须弥概况.md)正式建立跨国科研合作机制，在机械工程、元素理论与材料科学领域互补协作 |
| **2015** | **（背景） 提瓦特财团联盟 (TFC) 成立**，总部设于璃月港，信用货币体系基本建成 |
| **2015 后** | **两极产业格局成形，海底经济领土同步扩张**——梅洛彼得堡文旅化改造、水下数据中心与观光隧道用地开发兴起，发条数据通信集团运营虚空网络 |
| **2025 后** | **水下经济领土扩张提速**——白淞镇海底观光隧道完成二期扩建，[枫丹](./枫丹综述.md)廷外海水下数据中心集群新增多批次公开出让用地区块，竞标主体涵盖[稻妻](../稻妻/稻妻综述.md)跨海通信运营商与本土发条数据集团 |
| **2027** | 最高评议会设立**水下空间立法专项小组**——拟在现行水下地役权框架内明确权责划分，美露莘代表积极发声 |
| **2028** | **刺玫会在最高评议会推动扩大平民直接代表席位改革提案**——主张将部分豪门保底席位转为面向平民的普选产生，与豪门、行会的精英共和立场形成拉锯 |
| **2029** | 最高评议会席位重新核定（每四年一次）——豪门合计约 80~90 席，行会联合体约 50~60 席，刺玫会约 15~20 席，水神任命独立评审（含美露莘 3~4 席）约 20~30 席 |
| **2030** | **当前**——最高评议会约 200 席；平民席位改革提案仍在委员会审议阶段，[稻妻](../稻妻/稻妻综述.md)产业竞争促使精密机械行会推动技术标准壁垒 |

## 展望

| 纪年 | 事件 |
|:----|:----|
| **未来数年** | **平民席位改革博弈**——刺玫会与豪门、行会在精英共和框架下持续拉锯，席位核定动态反映各势力消长 |
| **中长期** | **水下空间产权纠纷**——梅洛彼得堡文旅化改造产权归属、水下数据中心与观光隧道用地地役权行使仍为法律界与评议会持续辩论议题 |
| **中长期** | **对[稻妻](../稻妻/稻妻综述.md)产业竞争**——稻妻半导体与消费电子冲击枫丹精密机械市场，倒逼产业向高端仪器、光学与发条自动化生态位收缩 |
