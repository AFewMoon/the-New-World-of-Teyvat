# 幕府大事记

> 注:本文档中的「TE」(Teyvat Era) 为提瓦特纪年缩写，以 TE 为统一纪年单位，记录[幕府](./稻妻/幕府/幕府综述.md)政权从远古至今 (TE 2030) 的重大历史事件。本文所述「[幕府](./稻妻/幕府/幕府综述.md)」指[雷电将军](./稻妻/幕府/幕府综述.md)及[幕府](./稻妻/幕府/幕府综述.md)中央政府直接管辖区域——鸣神岛、神无冢、[八酝岛](./稻妻/幕府/幕府行政区划.md)及鹤观岛。[海祇岛](./稻妻/海祇岛/海祇岛综述.md)自治领与[清籁岛](./稻妻/清籁岛/清籁岛综述.md)人民政府不在本文范围之内。全局性背景事件以「（背景）」标注。

## 大事年表

| 年份 (TE) | 事件 |
|:---------:|:----|
| **约 -100** | **（背景） 雷电姐妹统一稻妻诸岛**，雷电真主文、雷电影主武 |
| **400** | **锁国令初颁**，雷电将军封闭诸岛 |
| **1500** | **（背景） 坎瑞亚灾变**——雷电真陨落，雷电影继位，稻妻转向「永恒」；锁国政策全面推行，**三大奉行制度**（社奉行神里家、天领奉行九条家、勘定奉行柊家）固化为世袭封建权力结构 |
| **1700** | 锁国政策进一步强化，外国商人被限制于离岛一隅 |
| **1980** | **半导体产业起步**——踏鞴砂雷元素微雕刻蚀技术催生芯片制造雏形，特种冶金与雷元素储能产业随之兴起 |
| **2002** | **（背景） 锁国令终结、眼狩令废除**，稻妻重新向世界开放；**《地租改正条例》颁布** (2002~2006)——首次以法律形式确认土地私有制，藩阀领地登记为地契，实物地租改为货币地税；旧藩阀贵族凭「历史性权利认定」转化为新式大地主 |
| **2002 后** | **商务部崛起**——《产业振兴法》赋予勘定奉行下属商务部协调全国供应链的法定职责，财阀资本主义计划经济体制逐步成形 |
| **2012** | **（背景） [稻妻](./稻妻/稻妻综述.md)圆发行**，稻妻大藏省运作 |
| **2015~2020** | **幕府—[海祇岛](./稻妻/海祇岛/海祇岛综述.md)低烈度军事冲突**——踏鞴砂冶金产业扩张污染[海祇岛](./稻妻/海祇岛/海祇岛综述.md)周边海域，统一土地登记制度触及[海祇岛](./稻妻/海祇岛/海祇岛综述.md)传统土地共有制，双方多次发生武装冲突 |
| **2021** | **（背景）[清籁岛](./稻妻/清籁岛/清籁岛综述.md)革命成功**——三大财阀经柊信托协调对策，共同施压[幕府](./稻妻/幕府/幕府综述.md)采取强硬立场，并加强踏鞴砂与鸣神岛工业区劳动管控 |
| **2021~2030** | **[清籁岛](./稻妻/清籁岛/清籁岛综述.md)战争**——[幕府](./稻妻/幕府/幕府综述.md)军以提瓦特最先进装备发动数次大规模进攻，因士气低落、将领派系林立而在游击战与运动战中受挫，转入海上封锁与军事对峙 |
| **2020 年代** | **国家产业信息平台建成**——与[须弥](./须弥/须弥概况.md)虚空算力系统对接，财阀企业通过商务部平台系统化排挤中小企业；AI 配给制与社员卡制度在大中城市扩张 |
| **2025** | **《[稻妻](./稻妻/稻妻综述.md)群岛与[海祇岛](./稻妻/海祇岛/海祇岛综述.md)和解备忘录》签署**——[海祇岛](./稻妻/海祇岛/海祇岛综述.md)以自治领身份重返[稻妻](./稻妻/稻妻综述.md)国，[幕府](./稻妻/幕府/幕府综述.md)承认其高度自治并划设非军事区 |
| **2030** | **当前**——财阀垄断与土地分配不均（鸣神岛约六成耕地集中于不到 5% 的土地所有者手中）、[清籁岛](./稻妻/清籁岛/清籁岛综述.md)对峙与外部市场依赖构成治理核心矛盾 |

## 展望

| 纪年 | 事件 |
|:----|:----|
| **中长期** | **财阀体制结构性矛盾深化**——三大财阀通过国家产业信息平台持续排挤中小企业，生产社会化与生产资料私有化的矛盾在[清籁岛](./稻妻/清籁岛/清籁岛综述.md)革命后成为幕府辖区的显性议题 |
| **中长期** | **土地改革压力**——资产选举制虽在名义上松动，地权分配不平等仍是深刻的社会问题 |
