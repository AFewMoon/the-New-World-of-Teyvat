> 注:本文档中的「TE」(Teyvat Era) 为提瓦特纪年缩写，以 TE 为统一纪年单位，记录[海祇岛](./海祇岛综述.md)从远古至今 (TE 2030) 的重大历史事件。[海祇岛](./海祇岛综述.md)自 TE 2025 年《[幕府与海祇岛和解备忘录](../《幕府与海祇岛和解备忘录》.md)》签署后以「自治领」法律地位重返[稻妻](../稻妻综述.md)国。全局性背景事件以「（背景）」标注。

## 大事年表

| 年份 (TE) | 事件 |
|:---------:|:----|
| **魔神战争时期** | **大蛇奥罗巴斯将[海祇岛](./海祇岛综述.md)民众迁入珊瑚宫庇护**，建立以珊瑚信仰为核心的独立社会体系；大蛇东征战败，雷电将军对其击杀被视为「侵略」而非「平叛」，历史创伤以集体记忆形式代际传递 |
| **1500~2002** | **锁国令时期**——[幕府](../幕府/幕府综述.md)对[海祇岛](./海祇岛综述.md)实施严格海上封锁与贸易管制，珊瑚宫成为兼具精神权威与行政权力的治理中心，「圣土」制度固化 |
| **2002 后** | **矛盾激化**——踏鞴砂冶金产业扩张对周边海域造成严重污染，威胁海洋生物资源；[幕府](../幕府/幕府综述.md)统一土地登记制度触及[海祇岛](./海祇岛综述.md)传统土地共有制 |
| **2013** | **（背景） 海祇元发行**，[海祇岛](./海祇岛综述.md)财政与经济部成立 |
| **2015~2020** | **幕府—[海祇岛](./海祇岛综述.md)低烈度军事冲突**——[稻妻](../稻妻综述.md)国内战期间以「[海祇岛](./海祇岛综述.md)民族民主共和国」名义宣布独立，建立自己的政府与军队 |
| **2017** | **（背景）**[海祇岛](./海祇岛综述.md)以观察员身份加入提瓦特财团联盟 (TFC) |
| **2025** | **《[幕府与海祇岛和解备忘录](../《幕府与海祇岛和解备忘录》.md)》签署**——以「[海祇岛](./海祇岛综述.md)自治领」法律地位重返[稻妻](../稻妻综述.md)国，划设永久非军事区，组建[海祇岛](./海祇岛综述.md)自卫队，确立海祇元自由兑换与集体防御安排 |
| **2025~2030** | **合作社道路深化**——农村合作社（政企合一）成为二级行政单位，土地归合作社集体经营；珊瑚宫家族通过资本入股、技术入股与宗教影响在合作社体系中维持实质支配地位 |
| **2030** | **当前**——议会制共和政体运作，社会保障体系为[稻妻](../稻妻综述.md)群岛最完善；与[幕府](../幕府/幕府综述.md)关系处于「冷和平」状态 |

## 展望

| 纪年 | 事件 |
|:----|:----|
| **中长期** | **合作社体制的双重性格**——形式平等的合作社制度下，旧神官精英通过资本化路径延续影响力，珊瑚宫家族的实质支配地位面临民众质疑 |
| **中长期** | **财阀渗透与经济依赖**——神里、九条、柊三大财阀通过经济文化渠道持续渗透，清算体系与贸易渠道高度依赖璃月和[幕府](../幕府/幕府综述.md) |
