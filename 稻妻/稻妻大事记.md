# 稻妻大事记

> 注:本文档中的「TE」(Teyvat Era) 为提瓦特纪年缩写，以 TE 为统一纪年单位，记录[稻妻](稻妻/稻妻综述.md)群岛从远古至今 (TE 2030) 的重大历史事件。[稻妻](稻妻/稻妻综述.md)直接沿用提瓦特纪元纪年，无独立纪年系统。三大政治实体——[幕府](稻妻/幕府/幕府综述.md)、[海祇岛](稻妻/海祇岛/海祇岛综述.md)、[清籁岛](稻妻/清籁岛/清籁岛综述.md)——的独立大事记详见各子实体文档。全局性背景事件以「（背景）」标注。

## 大事年表

| 年份 (TE) | 事件 |
|:---------:|:----|
| **约 -100** | **（背景） 雷电姐妹统一稻妻诸岛**，雷电真主文、雷电影主武 |
| **0** | **（背景） 魔神战争终结**，七神体系确立，稻妻群岛归属雷电将军 |
| **400** | **锁国令初颁**，雷电将军封闭诸岛 |
| **1500** | **（背景） 坎瑞亚灾变**——雷电真陨落，雷电影继位，稻妻转向「永恒」；锁国政策全面推行，三大奉行制度逐步固化为世袭封建权力结构 |
| **1700** | 锁国政策进一步强化，外国商人被限制于离岛一隅 |
| **1980** | **稻妻半导体产业起步**——踏鞴砂雷元素微雕刻蚀技术催生芯片制造雏形 |
| **1999** | [清籁岛](稻妻/清籁岛/清籁岛综述.md)知识分子成立秘密读书会「火花俱乐部」（深秋，清籁城郊废弃天狗神社） |
| **2000** | 久岐忍创立[稻妻](稻妻/稻妻综述.md)贫农联盟（清籁岛雾谷村） |
| **2002** | **（背景） 锁国令终结、眼狩令废除**——雷电将军认知改变，[稻妻](稻妻/稻妻综述.md)重新向世界开放；**《地租改正条例》颁布** (2002~2006)——藩阀领地重新登记为地契，实物地租统一改为货币地税，旧藩阀贵族转化为新式大地主 |
| **2003** | 火花俱乐部与贫农联盟合流，成立**[稻妻](稻妻/稻妻综述.md)工农革命党**（9 月，石灰窑会议），枫原万叶当选党魁 |
| **2012** | **（背景） [稻妻](稻妻/稻妻综述.md)圆发行**，稻妻大藏省运作 |
| **2013** | **（背景） 海祇元发行**，[海祇岛](稻妻/海祇岛/海祇岛综述.md)自治领财政与经济部成立 |
| **2015~2020** | **幕府—[海祇岛](稻妻/海祇岛/海祇岛综述.md)低烈度军事冲突不断升级**——踏鞴砂冶金污染与统一土地登记之争激化矛盾；[稻妻](稻妻/稻妻综述.md)国内战期间，[海祇岛](稻妻/海祇岛/海祇岛综述.md)以「[海祇岛](稻妻/海祇岛/海祇岛综述.md)民族民主共和国」名义宣布独立 |
| **2017** | **（背景）** [海祇岛](稻妻/海祇岛/海祇岛综述.md)以观察员身份加入提瓦特财团联盟 (TFC) |
| **2021** | **经济危机爆发，[清籁岛](稻妻/清籁岛/清籁岛综述.md)社会主义革命成功**——工农革命党发动武装起义夺取全岛，10 月 10 日宣告成立[清籁岛](稻妻/清籁岛/清籁岛综述.md)人民政府；废除资产选举制与封建土地制度，土地收归公有并均田分配 |
| **2021~2030** | [幕府](稻妻/幕府/幕府综述.md)军多次进攻[清籁岛](稻妻/清籁岛/清籁岛综述.md)均受挫，双方陷入军事对峙；[幕府](稻妻/幕府/幕府综述.md)实施经济封锁与金融制裁，三大财阀加强辖区劳动管控 |
| **2025** | **《[稻妻](稻妻/稻妻综述.md)群岛与[海祇岛](稻妻/海祇岛/海祇岛综述.md)和解备忘录》签署**——[海祇岛](稻妻/海祇岛/海祇岛综述.md)以「自治领」法律地位重返[稻妻](稻妻/稻妻综述.md)国，划设永久非军事区，确立海祇元自由兑换与集体防御安排 |
| **2030** | **当前**——[幕府](稻妻/幕府/幕府综述.md)君主立宪、[海祇岛](稻妻/海祇岛/海祇岛综述.md)议会共和、[清籁岛](稻妻/清籁岛/清籁岛综述.md)人民民主专政三大政治实体并存的格局持续运作 |

## 展望

| 纪年 | 事件 |
|:----|:----|
| **未来数年** | **[清籁岛](稻妻/清籁岛/清籁岛综述.md)和平进程**——[幕府](稻妻/幕府/幕府综述.md)与[清籁岛](稻妻/清籁岛/清籁岛综述.md)之间军事对峙消耗双方资源，有限共识框架（群岛运动会、文化遗产保护、灾害预警共享）下和平进程遥遥无期 |
| **中长期** | **[幕府](稻妻/幕府/幕府综述.md)财阀体制的结构性矛盾**——生产社会化与生产资料私有化之间的张力、土地分配不均与中小企业困境持续积累 |
