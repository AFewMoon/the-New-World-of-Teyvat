> 注:本文档中的「TE」(Teyvat Era) 为提瓦特纪年缩写，以 TE 为统一纪年单位，记录[稻妻](./稻妻综述.md)群岛从远古至今 (TE 2030) 的重大历史事件。[稻妻](./稻妻综述.md)直接沿用提瓦特纪元纪年，无独立纪年系统。[三大政治实体](./稻妻综述.md)——[幕府](./幕府/幕府综述.md)、[海祇岛](./海祇岛/海祇岛综述.md)、[清籁岛](./清籁岛/清籁岛综述.md)——的独立大事记详见各子实体文档。全局性背景事件以「（背景）」标注。

## 大事年表

| 年份 (TE) | 事件 |
|:---------:|:----|
| **魔神战争时期** | **大蛇奥罗巴斯将[海祇岛](./海祇岛/海祇岛综述.md)民众迁入珊瑚宫庇护**——建立以珊瑚信仰为核心、脱离[幕府](./幕府/幕府综述.md)直接统治的独立社会体系；大蛇东征战败，雷电将军对其击杀被视为「侵略」而非「平叛」，历史创伤以集体记忆形式代际传递 |
| **约 -100** | **（背景） 雷电姐妹统一稻妻诸岛**，雷电真主文、雷电影主武 |
| **0** | **（背景） 魔神战争终结**，七神体系确立，稻妻群岛归属雷电将军 |
| **400** | **锁国令初颁**，雷电将军封闭诸岛 |
| **1500** | **（背景） 坎瑞亚灾变**——雷电真陨落，雷电影继位，稻妻转向「永恒」；锁国政策全面推行，**三大奉行制度**（社奉行神里家、天领奉行九条家、勘定奉行柊家）固化为世袭封建权力结构；资产选举制将选举权与土地所有权绑定，[海祇岛](./海祇岛/海祇岛综述.md)「圣土」制度随之固化 |
| **1700** | 锁国政策进一步强化，外国商人被限制于离岛一隅 |
| **1980** | **半导体产业起步**——踏鞴砂雷元素微雕刻蚀技术催生芯片制造雏形，特种冶金与雷元素储能产业随之兴起 |
| **1998** | **（背景）**多国开始筹建本币信用体系，摩拉通缩隐忧引发各国财政策略调整 |
| **1999** | [清籁岛](./清籁岛/清籁岛综述.md)知识分子成立秘密读书会「火花俱乐部」（深秋，清籁城郊废弃天狗神社） |
| **2000** | 久岐忍创立[稻妻](./稻妻综述.md)贫农联盟（春，清籁岛雾谷村）——以「算账式启蒙」发动农民，组织互助、抗租抗税与信使网络，到 2001 年底已覆盖[清籁岛](./清籁岛/清籁岛综述.md)北部二十三个村庄 |
| **2002** | **（背景） 锁国令终结、眼狩令废除**——雷电将军认知改变，[稻妻](./稻妻综述.md)重新向世界开放；**《地租改正条例》颁布** (2002~2006)——藩阀领地重新登记为地契，实物地租统一改为货币地税，旧藩阀贵族凭「历史性权利认定」转化为新式大地主；**商务部崛起**——《产业振兴法》赋予勘定奉行下属商务部协调全国供应链的法定职责 |
| **2002 后** | 财阀通过「国家产业信息平台」加速对[清籁岛](./清籁岛/清籁岛综述.md)玉矿与木材的资源抽吸；踏鞴砂冶金产业扩张污染[海祇岛](./海祇岛/海祇岛综述.md)周边海域、统一土地登记制度触及[海祇岛](./海祇岛/海祇岛综述.md)传统土地共有制，双方矛盾激化 |
| **2003** | 火花俱乐部与贫农联盟合流，成立**[稻妻](./稻妻综述.md)工农革命党**（9 月，石灰窑会议），枫原万叶当选党魁；此后基层组织扩展至[清籁岛](./清籁岛/清籁岛综述.md)全境云雾矿区、竹林村落与清籁港区 |
| **2005~2012** | **（背景） 信用货币时代开启**——摩拉停铸通缩效应向全大陆扩散，七国相继研究并发行主权信用货币：2005 通缩扩散、2006 替代货币方案研究、2008 至冬卢布、2010 璃月元与枫丹科朗、2011 蒙德镑、2012 [稻妻](./稻妻综述.md)圆 |
| **2012** | **（背景） [稻妻](./稻妻综述.md)圆发行**，稻妻大藏省运作 |
| **2013** | **（背景） 海祇元发行**，[海祇岛](./海祇岛/海祇岛综述.md)自治领财政与经济部成立 |
| **2015** | **（背景） 提瓦特财团联盟 (TFC) 成立**，总部设于璃月港 |
| **2015~2020** | **幕府—[海祇岛](./海祇岛/海祇岛综述.md)低烈度军事冲突不断升级**——踏鞴砂冶金污染与统一土地登记之争激化矛盾；[稻妻](./稻妻综述.md)国内战期间，[海祇岛](./海祇岛/海祇岛综述.md)以「[海祇岛](./海祇岛/海祇岛综述.md)民族民主共和国」名义宣布独立，建立自己的政府与军队 |
| **2017** | **（背景）** [海祇岛](./海祇岛/海祇岛综述.md)以观察员身份加入提瓦特财团联盟 (TFC) |
| **2020 年代** | **国家产业信息平台建成**——与[须弥](../须弥/须弥概况.md)虚空算力系统对接，财阀企业经商务部平台系统化排挤中小企业；AI 配给制与社员卡制度在大中城市扩张 |
| **2021** | **经济危机爆发，[清籁岛](./清籁岛/清籁岛综述.md)社会主义革命成功**——工农革命党发动武装起义夺取全岛，10 月 10 日宣告成立[清籁岛](./清籁岛/清籁岛综述.md)人民政府；颁布《[清籁岛](./清籁岛/清籁岛综述.md)宪法》，废除资产选举制与封建土地制度，土地收归公有并按家庭人口均等分配；三大财阀经柊信托协调对策，共同施压[幕府](./幕府/幕府综述.md)采取强硬立场 |
| **2021~2030** | **军事对峙与封锁**——[幕府](./幕府/幕府综述.md)军以提瓦特最先进装备发动数次大规模进攻，因士气低落、将领派系林立而在游击战与运动战中受挫，转入海上封锁与军事对峙；三大财阀加强踏鞴砂与鸣神岛工业区劳动管控；[清籁岛](./清籁岛/清籁岛综述.md)人民卫队全民皆兵，对外贸易主要经[海祇岛](./海祇岛/海祇岛综述.md)中转 |
| **2025** | **《[稻妻](./稻妻综述.md)群岛与[海祇岛](./海祇岛/海祇岛综述.md)和解备忘录》签署**——[海祇岛](./海祇岛/海祇岛综述.md)以「自治领」法律地位重返[稻妻](./稻妻综述.md)国，划设永久非军事区，组建[海祇岛](./海祇岛/海祇岛综述.md)自卫队，确立海祇元自由兑换与集体防御安排 |
| **2025~2030** | [海祇岛](./海祇岛/海祇岛综述.md)合作社道路深化——农村合作社（政企合一）成为二级行政单位，土地归合作社集体经营；珊瑚宫家族通过资本入股、技术入股与宗教影响在合作社体系中维持实质支配地位 |
| **2030** | **当前**——[幕府](./幕府/幕府综述.md)君主立宪、[海祇岛](./海祇岛/海祇岛综述.md)议会共和、[清籁岛](./清籁岛/清籁岛综述.md)人民民主专政三大政治实体并存的格局持续运作；摩拉通缩持续深化，TFC 积极推进数字摩拉与成员国本币结算网络 |

## 展望

| 纪年 | 事件 |
|:----|:----|
| **未来数年** | **[清籁岛](./清籁岛/清籁岛综述.md)和平进程**——[幕府](./幕府/幕府综述.md)与[清籁岛](./清籁岛/清籁岛综述.md)之间军事对峙消耗双方资源，有限共识框架（群岛运动会、文化遗产保护、灾害预警共享）下和平进程遥遥无期 |
| **中长期** | **[幕府](./幕府/幕府综述.md)财阀体制的结构性矛盾**——生产社会化与生产资料私有化之间的张力、土地分配不均与中小企业困境持续积累 |
| **中长期** | [海祇岛](./海祇岛/海祇岛综述.md)合作社体制的双重性格——旧神官精英通过资本化路径延续影响力，珊瑚宫家族的实质支配地位面临民众质疑 |
