# 蒙德大事记

> 注:本文档中的「TE」(Teyvat Era) 为提瓦特纪年缩写，以 TE 为统一纪年单位，记录[蒙德](蒙德/蒙德综述.md)从远古至今 (TE 2030) 的重大历史事件。[蒙德](蒙德/蒙德综述.md)自由合众国自 TE 1000 年 9 月 1 日「自由宣言」颁布起建国，直接沿用提瓦特纪元纪年，无独立纪年系统。全局性背景事件以「（背景）」标注。

## 大事年表

| 年份 (TE) | 事件 |
|:---------:|:----|
| **约 -700** | **（背景） 迭卡拉庇安统治旧蒙德**，以烈风筑墙，建立高塔孤王统治 |
| **约 -600** | **高塔孤王覆灭**——起义军推翻迭卡拉庇安，巴巴托斯成为风神；北风狼王安德留斯放弃神位，力量注入大地 |
| **600** | **深渊灾厄**——腐殖之龙杜林袭击[蒙德](蒙德/蒙德综述.md)，特瓦林与旅行者联手击败之 |
| **700** | **蒙德四风守护体系确立**，蒲公英骑士制度正式建立 |
| **1000** | **温妮莎革命**——来自穆纳塔族的温妮莎领导人民起义，推翻以劳伦斯家族为首的旧贵族统治；9 月 1 日颁布「自由宣言」，西风骑士团正式建立，温妮莎成为首任「狮牙骑士」，蒙德开启自由城邦新纪元；地产选举制时期自此开始 |
| **1750** | **蒙德风力发电技术萌芽**，星落平原首批风能实验设施建成 |
| **1900** | **蒙德风能开发起步**，星落平原首批规模化风力发电机组落成 |
| **1950** | 星落平原风力发电场进入规模化建设阶段，成为提瓦特首个绿电基地 |
| **约 1980~1990** | 工业扩张期——码头工人、失地农民与底层手工业者组成「蒙德自由工人联谊会」，早期诉求集中于改善工作条件与提高工资 |
| **1990 年代** | **西风骑士团联邦化改革**——团长不再代理全国政务，行政权移交民选内阁；治安、消防、民防职能分立，骑士团转型为联邦国防军，最高统帅自动兼任联邦总统 |
| **1995** | **蒲公英酒业联盟完成产业整合**；**（背景） 提瓦特大陆联合交易所成立**，各国骨干企业陆续上市 |
| **1998** | 风力发电场扩建征地冲突——知识分子与工人首次联合行动（持续 23 天抗议），促成[蒙德无政府主义者—自由工人联盟 (MAFWA)](蒙德/蒙德政治概况.md)正式合并 |
| **2001** | **（背景） 龙灾终结**——旅行者击退被深渊腐蚀的风魔龙特瓦林，西风骑士团重建四风守护 |
| **2008~2009** | **摩拉通缩引发全面经济危机**——蒙德镑尚未发行，失业率从 3.2% 飙升至 11.7%，荆夫港码头与星落湖矿区爆发多起自发性罢工 |
| **2009** | **普选运动**——3 月约 8,000 名失业工人在蒙德城中央广场集会，示威浪潮持续 47 天，高峰时参与人数超过 2 万人；6 月上议院通过《普选改革法案》，废除与地产挂钩的选举资格门槛；秋，旧贵族、骑士团保守派与教会势力重组为蒙德保守党；自由党「红叶会」改革派脱离，另立自由民主党 |
| **2010** | **蒙德举行历史上第一次全民普选**；**（背景） 璃蒙基础条约签署**，为超国家一体化奠定法律框架 |
| **2011** | **蒙德镑发行，蒙德中央银行成立**；自由民主党吸纳自由意志主义、古典自由主义与社会自由主义团体重组，定名蒙德自由党 |
| **2012** | **蒙德工党正式成立**——127 名代表在蒙德城郊废弃酒窖召开建党大会；首次参选即获 31.4% 得票率、63 席，成为第一大党，与自由党组建联合政府 |
| **2015** | **（背景） 提瓦特财团联盟 (TFC) 成立**；大选中工党增至 70 席，自由党—保守党联合窗口期出现 |
| **2017** | MAFWA 成员在荆夫港组织反对港口私有化的大型集会（约 1,200 人），为 2000 年代以来蒙德最大规模非法集会 |
| **2018** | 大选中工党获 72 席，与自由党再次联合执政；工党主导《情报监督法》通过，国内监控行为须报由下议院特别委员会季度审核 |
| **2019** | **《最低工资与基本劳动保障法》签署生效**（4 月）——最低小时工资设定为城镇劳动者中位数时薪的 42%，每周最高工时 48 小时 |
| **2020** | **晨曦酒庄领—清泉领水权纠纷案宣判**——联邦最高法院确立水资源跨领共享原则，晨曦酒庄领须按年度灌溉取水量的 22% 支付水资源补偿金；《网络安全与信息秩序法案》二读表决被否决（104 票反对、89 票赞成） |
| **2021** | 大选中工党获 67 席（第一大党但优势缩小），与自由党续签联合协议；MAFWA 成员两次冲入晨曦酒庄领风力发电站配电室，切断输电线路造成区域性停电 5 小时 |
| **2022** | 工党青年团发起「绿色蒙德」行动计划，推动老旧风电机组替换与城市废物回收系统升级；安柏、优菈就《情报监督法》通信拦截条款向最高法院提起宪法诉讼 |
| **2024** | 大选中工党获 70 席，与自由党组建联合政府 |
| **2026** | **最高法院裁定《情报监督法》通信拦截条款部分违宪**（4 月）——公民通信拦截须事先取得法院令状，被视为自由党左翼在公民自由议题上的里程碑式胜利 |
| **2027** | 大选中工党获 68 席，工党—自由党联合政府连任（11 月宣誓就职）；保守党回升至 52 席 |
| **2028** | **晨曦酒庄试点国有化收购完成**——工党左派「蒲公英酒业联盟核心资产国有化」动议以折中方案落地 |
| **2030** | **当前**——今秋举行下议院大选；蒲公英酒业联盟国有化试点成果、数字身份认证体系立法与监控权限博弈成为核心焦点议题 |

## 展望

| 纪年 | 事件 |
|:----|:----|
| **TE 2030 年秋** | **下议院大选**——工党—自由党联合政府选后前景成为各党博弈核心变量；工党左派酝酿将国有化试点扩大至第二家核心酒庄 |
| **未来数年** | **数字身份认证体系立法博弈**——保守党威权派推动建立国家级统一数字身份系统，自由党左翼视为「迈向全面监控的第一步」 |
