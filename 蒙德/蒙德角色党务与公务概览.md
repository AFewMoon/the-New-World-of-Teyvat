# 蒙德角色党务与公务概览

> 本文档系统梳理蒙德自由合众国各政治角色的**党内职务**（党务）与**政府/国家机构职务**（公务），以政党归属为纲，逐一列明每位角色的双重身份体系。

---

| 类别 | 职务 |
|------|------|
| **党务** | 工党主席（左派/民主社会主义派代表） |
| **公务** | 西风骑士团骑兵队长、情报与对外联络处主任、下议院议员 |

| **概述** | 凯亚作为工党党魁，执掌党务全局，同时以骑兵队长身份在骑士团内拥有军事指挥权，情报与对外联络处主任一职更使他成为蒙德情报体系的总负责人。其"暗面执掌者"的过往经历，为这套双重身份提供了深厚积淀。 |
