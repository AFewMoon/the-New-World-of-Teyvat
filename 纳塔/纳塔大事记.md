# 纳塔大事记

> 注：本文档中的「TE」(Teyvat Era) 为提瓦特纪年缩写，以 TE 为统一纪年单位，记录[纳塔](./纳塔综述.md)从远古至今 (TE 2030) 的重大历史事件。[纳塔](./纳塔综述.md)联盟于总体保卫战前夕以《圣火盟约》改组为超国家制，直接沿用提瓦特纪元纪年，无独立纪年系统。全局性背景事件以「（背景）」标注。

## 大事年表

| 年份 (TE) | 事件 |
|:---------:|:----|
| **远古** | **初代火神[希巴拉克](./古名与还魂诗——纳塔传统信仰体系.md)与死之执政若娜瓦订立契约**——确立「[归火圣夜巡礼](./古名与还魂诗——纳塔传统信仰体系.md)」与「还魂诗」的规则体系（「胜者重燃，败者成灰」），古名信仰自此发端 |
| **0** | **（背景） 魔神战争终结**——七神体系确立，[希巴拉克](./古名与还魂诗——纳塔传统信仰体系.md)以初代火神身份位列七神，[纳塔](./纳塔综述.md)进入尘世七执政秩序 |
| **1500** | **（背景） 坎瑞亚灾变**——无神国度坎瑞亚覆灭，连锁灾祸席卷七国 |
| **约 1530** | **坎瑞亚役战争（深渊战争）爆发**——深渊入侵全面升级；英雄[特诺切](./纳塔角色档案.md)首提「六部族联合」凝聚各部族，牺牲后古名破碎无法复活，遗志未竟 |
| **约 1530~1550** | **时任火神[玛薇卡](./纳塔角色档案.md)启动五百年计划**——继承特诺切遗志，以五百年为跨度将生命存入圣火、跨越时间在未来苏醒，聚集六位英雄迎战深渊 |
| **约 1550** | **纳塔巡夜者制度成型**——六部族正式确立以古名持有者为核心的巡夜者编制，深渊前线常态化防御体系建立 |
| **约 1700** | **纳塔六部族联合首领制确立**——各部族首领组成常设议事机构，在外交与国防领域实现统一协调，为后世联盟体制奠定制度基础 |
| **约 1700~2000** | **五百年深渊对峙**——深渊入侵时有发生，各部族在并肩作战中锻造集体认同；物资匮乏环境下民众自发结成互助网络，[纳塔](./纳塔综述.md)群众集体主义传统在战火中沉淀 |
| **1970** | **纳塔地热技术突破**——火山地热发电站并网运行，高耗能特种材料产业兴起 |
| **1992** | **纳塔燃素城际线路投入试运行**——沿铁路线位实现能源网、信息网、交通网三网融合 |
| **1997** | **纳塔六部族联合能源协议签署**——燃素管廊沿交通线位敷设 |
| **约 2002~2004** | **总体保卫战前夕制度转型**——六部族从部落首领制平稳过渡为总统制共和国，建立现代化行政、立法与司法体系；《圣火盟约》签署，联盟改组为超国家制，外交、国防、货币发行与古名信仰管理四项核心主权让渡联盟 |
| **2004** | **（背景） 深渊战争大规模爆发**，六部族全面反击 |
| **2005** | **总体保卫战胜利**——旅行者完成主线作战任务，深渊主力被击退，巡夜者战争宣告终结；**[玛薇卡](./纳塔角色档案.md)被推举为联盟首任总统**，完成[火神](./纳塔角色档案.md)之位传承（卸任），[纳塔](./纳塔综述.md)不再设有火神常设职位 |
| **约 2002~2024** | **「土地换和平」土地确权**——联盟宪章确立土地所有权归各共和国政府，各部落以放弃对争议领土的武力索求为代价，换取已控区域土地所有权的法律承认，各共和国完成首次系统性土地登记与确权 |
| **约 2005~2010** | **战后重建全面展开**——[纳塔](./纳塔综述.md)团结联盟一党执政，战时全民动员体制向和平时期过渡；生产建设兵团承担道路、水利、屯田与矿区修复等重建任务；悠悠度假乡（特诺[奇兹托克群岛](./悠悠度假乡——特诺奇兹托克群岛度假胜地.md)）由联盟代议院决议兴建 |
| **约 2005~2020** | **跨共和国高速铁路网络建设**——以[圣火市](./纳塔行政区划.md)为枢纽的六条放射线高速铁路相继建成，依托地热电力实现全境电气化 |
| **约 2010~2020** | **游隙灵道城际网络建设**——以[燃素](./纳塔综述.md)能量通路为轨道的空中轨道交通在各共和国首府与卫星城镇间铺开，形成提瓦特独有的城际交通形态 |
| **2012** | **（背景） [纳塔](./纳塔综述.md)鎏金币发行**，纳塔中央银行运作 |
| **2015** | **（背景） 提瓦特财团联盟 (TFC) 成立**，[纳塔](./纳塔综述.md)为创始成员国 |
| **约 2020 年代** | **燃素城际线路规模化推广**——「发展三角」示范线（[圣火市](./纳塔行政区划.md)—铁砧城—沃原城，约 650 km）率先试点，至 TE 2030 各共和国首府放射线全部建成投运 |
| **约 2020 年代** | **纳塔—须弥能源走廊贯通**——地热电力夜间外送[须弥](../须弥/须弥概况.md)沙漠算力中心、[须弥](../须弥/须弥概况.md)沙漠光伏白天反向调峰，形成双向互补的能源—算力合作 |
| **2024** | **燃素大规模工业应用开启资源产权革命**——地表所有权与地下矿产权相分离的双层产权结构确立，[燃素](./纳塔综述.md)管理局成立，统一管制勘探开采许可与配额 |
| **2025~2030** | **多党协商萌芽**——竞焰党、共和之声、绿色熔岩、工人火炬等新兴政治力量相继在共和国议会赢得席位，个别共和国出现「团结党—新党」联合协商施政试点 |
| **2027** | **团结联盟全国代表大会**——党内「改革派」与「正统派」就多党协商达成阶段性妥协，同意在共和国层面试点政治协商机制，被视为「一党体制松动」的正式化标志 |
| **2030** | **当前**——总统换届选举年；团结党在联盟代议院仍保持约 70% 以上席位，多党协商能否从各共和国层面走向联盟层面成为最大焦点议题 |

## 展望

| 纪年 | 事件 |
|:----|:----|
| **TE 2030 年** | **总统换届选举**——是否出现联盟层面多候选人竞争与程序化辩论，是判断多党协商转型的关键节点；部分新兴力量主张严格适用任期条款 |
| **中长期** | **外汇依赖与被迫产业升级**——精密设备进口与维护支出年均增长 8~10%，快于财政收入增速，推动燃素替代设备研发与本地化进程 |
| **中长期** | **一党专政向多党协商过渡**——新兴政治力量需与[纳塔](./纳塔综述.md)深厚的群众集体主义传统建立连接 |
| **未来数年** | **军队结构性改革**——圣火军团大裁兵、生产建设兵团剥离军队序列、禁止军队经商及与民争利等议题提上联盟代议院议程 |
| **未来十年** | **燃素城际线路深化推广**——在放射线基础上逐步覆盖各共和国首府间联络线，拓展城域网与能源调峰应用 |
| **中长期** | **古名信仰的和平转型**——还魂诗因大灵力量衰退转为象征性仪式，古名商业化在[古名院](./纳塔政治概况.md)监管框架下渐进拓展，神圣性与商业性的边界持续博弈 |
