# 纳塔联盟经济与产业概况

> **货币说明**：纳塔中央银行发行的**纳塔鎏金币**（NLG，1 摩拉 ≈ 2.3 纳塔鎏金币）为纳塔联盟法定货币。摩拉仍作为国际储备资产继续流通，在跨境大宗商品交易中广泛使用。

---

## 一、经济总览

纳塔联盟的经济体制可概括为**「联盟统一市场 + 共和国自主发展」**的双层模式。联盟层面负责货币发行、关税政策、重大基础设施协调和体育竞技国家标准；各共和国在地方税收、土地管理、文化经济和部族特色产业方面享有充分的自主权。

纳塔经济高度依赖火山环境，形成了以**地热能源开发、体育与竞技产业、特种新材料研发、温泉康养旅游**为四大支柱的特色经济体系。在全国约 86 万平方千米的国土面积上，活跃火山带提供的地热资源、火山灰土壤的矿业价值、以及独特的「燃素」资源，使纳塔在全球产业链中占据了不可替代的生态位。

**2024 年主要经济指标（估计）：**

| 指标 | 数值 |
|------|:----:|
| 联盟 GDP（名义） | 约 4,200 亿摩拉 |
| 人均 GDP | 约 26,900 摩拉 |
| GDP 增速 | 4.8% |
| 通胀率（鎏金币计） | 3.1% |
| 失业率 | 5.2% |
| 出口总额 | 约 1,100 亿摩拉 |
| 进口总额 | 约 950 亿摩拉 |

## 二、四大支柱产业详解

### 2.1 地热能源开发

纳塔是全球地热技术最先进的国家，活跃的火山带为全国提供了近乎无限的地热能源。

**发电规模：**
- 全联盟地热发电总装机容量约 18 GW（全球第一）
- 每年发电量约 130 TWh，满足国内全部电力需求后仍有约 35% 的盈余
- 盈余电力通过超高压输电线路向须弥沙漠地区出口，主要供应须弥的绿色算力中心和光伏互补电网

**产业链：**
- **上游**：地热勘探（纳塔地质调查院 + 各共和国矿业公司）
- **中游**：地热电站建设与运营（纳塔地热集团——联盟控股 51%，各共和国参股）
- **下游**：地热技术出口（勘探设备、钻井技术、热交换系统）
- **衍生**：地热供暖（覆盖全国主要城镇）、地热温室农业（火山灰土壤 + 地热恒温，实现全年蔬果种植）

**主要企业：**
- 纳塔地热集团（Nathermal Group）：联盟最大国有能源企业，总部在回声之子共和国铁砧城
- 熔炉能源（Furnace Energy）：回声之子共和国控股企业，专注地热发电站运营
- 暖源科技（Warm Source Tech）：流泉之众共和国民营企业，从事地热供暖系统开发

### 2.2 体育与竞技产业

竞技精神刻入纳塔人的民族基因。体育产业是纳塔最具国际影响力的经济支柱，也是各共和国参与度最高、与古名信仰关系最紧密的产业。

**赛事体系：**

| 赛事名称 | 类型 | 国际影响力 | 举办地轮换 |
|----------|------|:---------:|:--------:|
| 归火圣夜巡礼 | 综合竞技（年度最高仪式性赛事） | 极高 | 圣火市 |
| 纳塔烈焰竞速 | 极限竞速（穿越火山地形） | 高 | 各共和国轮办 |
| 火山空降锦标赛 | 高空跳伞/滑翔 | 高 | 花羽会 + 悬木人 |
| 熔岩搏击联赛 | 竞技格斗 | 中高 | 沃陆之邦 |
| 匿叶龙越野赛 | 龙伙伴骑行竞速 | 中 | 悬木人 |
| 各共和国联赛 | 地方性综合竞技 | 各国内 | 各共和国自行组织 |

**产业规模：**
- 赛事转播权收入：约 180 亿摩拉/年（全球最大体育赛事转播权出口国之一）
- 体育旅游收入：约 120 亿摩拉/年
- 体育装备制造产值：约 90 亿摩拉/年
- 电竞产业收入：约 50 亿摩拉/年（通过须弥算力平台运营）

**体育装备制造：**
纳塔本土体育装备品牌在耐高温运动装备、极限防护具、训练用竞技武器、龙伙伴骑行装备等领域占据全球市场主导地位。代表性企业包括：

- **烈焰锻造（Flame Forge）**：回声之子共和国品牌，专注竞技武器与护甲
- **熔岩足（Lava Step）**：沃陆之邦共和国品牌，全球顶级极限运动鞋类制造商
- **匿叶（Leaf Hider）**：悬木人共和国品牌，龙伙伴装备全球第一品牌
- **轻羽（Light Feather）**：花羽会共和国品牌，滑翔翼与翼装飞行设备制造商

### 2.3 特种新材料研发

火山环境中蕴藏的独特矿物和燃素资源，使纳塔在全球新材料领域占据了不可替代的生态位。

**核心产品矩阵：**

| 材料类别 | 主要用途 | 全球市场占有率 |
|----------|----------|:------------:|
| 火山碳化钨基复合材料 | 高温炉衬、火箭喷嘴、深地钻头 | ~75% |
| 燃素强化合金 | 高能燃料储运容器、龙伙伴装甲 | ~90% |
| 玄武岩连续纤维 | 建筑增强材料、防火隔热层 | ~60% |
| 热液硫化矿物催化剂 | 化工催化、新能源电池 | ~55% |
| 火山玻璃纤维（黑曜石纺丝） | 精密光学、高端传感器 | ~80% |

**主要研发机构：**
- **纳塔材料科学研究院**（联盟级，圣火市）
- **回声冶金研究中心**（回声之子共和国，专注金属与合金）
- **沃陆新材料实验基地**（沃陆之邦共和国，专注复合材料与燃素应用）
- **烟谜主矿物研究所**（烟谜主共和国，专注火山矿物与晶体）

**龙伙伴装备制造：**
纳塔独有的特色产业。为龙伙伴（匿叶龙、嵴锋龙、绒翼龙、重甲龙等）定制的鞍具、护甲、通讯装备、健康监测设备，是高级手工业、材料科学和生物工程技术的结合产物。一只竞技级龙伙伴的全套装备价值可达 50~200 万摩拉。全球龙伙伴装备市场基本由纳塔垄断。

### 2.4 温泉康养旅游

遍布全国的火山温泉资源，结合各部族传统理疗技法，使纳塔成为提瓦特首屈一指的康养旅游目的地。

**主要度假区：**

| 地区 | 特色 | 目标客群 |
|------|------|----------|
| 流泉之众 - 沸汤县 | 大型天然温泉群，顶级度假村聚集 | 枫丹、璃月高净值游客 |
| 烟谜主 - 灵泉县 | 萨满医学 + 温泉疗法结合 | 医疗康养游客 |
| 回声之子 - 熔炉县 | 火山蒸汽浴 + 竞技体验 | 青年冒险游客 |
| 流泉之众 - 黑沙县 | 黑色火山沙滩 + 海滨温泉 | 家庭及休闲游客 |
| 花羽会 - 风峡城 | 高原峡谷温泉 + 滑翔体验 | 极限运动爱好者 |

**医疗康养：**
纳塔温泉水的特殊矿物成分（富含各种硫化物、微量元素和火山矿物质）被认为对皮肤病、关节炎、呼吸道疾病和慢性疲劳综合征有显著疗效。流泉之众的「守烛人」医疗传承与烟谜主的萨满医学体系，结合现代医疗技术，形成了完整的康养医学体系。

## 三、联盟财政体系

### 3.1 联盟财政收入来源

| 来源 | 占比 | 说明 |
|------|:---:|------|
| 各共和国上缴款 | ~45% | 按各共和国 GDP 比例协商确定的上缴份额 |
| 关税收入 | ~25% | 联盟对进口商品统一征收的关税 |
| 联盟自有资产收益 | ~15% | 联盟控股企业的分红、国有土地租金等 |
| 古名认证与管理费 | ~8% | 古名院收取的古名认证、转让和商业使用许可费用 |
| 归火圣夜巡礼收入 | ~7% | 赛事转播权、门票、赞助等（联盟层面份额） |

### 3.2 联盟财政支出方向

| 支出类别 | 占比 | 说明 |
|----------|:---:|------|
| 国防（圣火军团） | ~18% | 联盟武装力量维持及装备更新 |
| 联盟行政 | ~15% | 代议院、委员会、法院等机构运行 |
| 跨共和国基础设施 | ~22% | 联盟级公路、铁路、输电网络建设维护 |
| 归火圣夜巡礼及古名事务 | ~12% | 赛事组织、古名院运行、大灵祭祀 |
| 联盟科研基金 | ~10% | 地热技术、新材料、体育科学等基础研究 |
| 共和国均衡发展补贴 | ~15% | 对经济相对落后共和国的转移支付 |
| 应急储备 | ~8% | 自然灾害（火山喷发/地震）应急响应 |

## 四、各共和国经济特色

### 4.1 回声之子共和国——能源与冶金中心

- **GDP 贡献**：约占联盟 26%
- **主导产业**：地热发电（联盟 40% 装机容量）、钢铁及有色金属冶炼、竞技装备锻造
- **特色经济指标**：工业用电量全联盟最高（高耗能产业集中）
- **主要出口**：地热发电设备、锻造竞技武器、工业高温炉具
- **与联盟的关系**：地热集团总部所在地，联盟能源命脉所在

### 4.2 流泉之众共和国——康养与贸易枢纽

- **GDP 贡献**：约占联盟 20%
- **主导产业**：温泉康养旅游、海洋渔业、海产加工、海外贸易
- **特色经济指标**：旅游收入占共和国 GDP 约 40%
- **主要出口**：康养服务、海产品、温泉疗养技术
- **主要贸易伙伴**：暖泉港是联盟第一大港口，与枫丹、稻妻、璃月均有定期航线

### 4.3 悬木人共和国——龙伙伴与经济林业

- **GDP 贡献**：约占联盟 15%
- **主导产业**：龙伙伴驯养与繁育、高山农业、极限运动旅游、木材加工
- **特色经济指标**：龙伙伴经济（驯养、装备、赛事）占共和国 GDP 约 35%
- **主要出口**：龙伙伴幼体、龙伙伴装备（与沃陆合作）、高山咖啡与香料

### 4.4 花羽会共和国——通讯与纺织业

- **GDP 贡献**：约占联盟 13%
- **主导产业**：通讯技术研发、高原牧业、毛纺织业、滑翔赛事经济
- **特色经济指标**：联盟通讯设备专利约 60% 来自花羽会企业
- **主要出口**：特种通讯设备、高原龙羊毛织品、滑翔装备

### 4.5 沃陆之邦共和国——体育与先进制造

- **GDP 贡献**：约占联盟 27%（人口最多、经济体量最大）
- **主导产业**：体育训练与赛事经济、特种新材料研发制造、竞技装备大规模生产
- **特色经济指标**：拥有全联盟最多的体育企业和注册运动员
- **主要出口**：特种新材料、竞技装备、体育赛事转播权
- **与联盟的关系**：联盟体育竞技产业的核心基地

### 4.6 烟谜主共和国——矿业与信仰经济

- **GDP 贡献**：约占联盟 15%
- **主导产业**：火山矿物及稀有晶体开采、萨满医学、洞穴旅游、古名商业服务
- **特色经济指标**：古名认证及商业使用收入占共和国 GDP 约 12%
- **主要出口**：火山矿物、稀有晶体、萨满医学制剂、古名品牌授权

## 五、燃素经济

### 5.1 燃素是什么

燃素（Phlogiston）是纳塔火山深处孕育的一种高能量物质，也是古名信仰的物质基础——圣火的核心燃料。在战争中，燃素为巡夜者战争的「还魂诗」提供了能量；在和平年代，燃素的工业价值被充分发掘。

### 5.2 工业应用

- **高能燃料**：燃素提取物的能量密度约为传统化石燃料的 8~12 倍，已广泛应用于纳塔地热电站的调峰机组、稻妻火箭发射的推进剂、至冬极地装备的便携能源。
- **材料强化**：燃素与金属冶炼的结合产生了燃素强化合金——纳塔特种新材料的核心产品之一。
- **医学应用**：微量燃素化合物在萨满医学中被用于创伤愈合和神经修复，近年已进入临床试验阶段。

### 5.3 管理机制

燃素的开采、提纯和流通受到联盟法律的严格管制。联盟委员会下设「燃素管理局」，负责：
- 颁发勘探与开采许可证
- 设定开采配额
- 规范交易市场
- 监督燃素安全（燃素具有高度可燃性和一定毒性）

各共和国境内的燃素矿藏所有权归各共和国，但跨共和国的燃素运输和国际贸易需获得燃素管理局的许可。

## 六、国际贸易

### 6.1 主要贸易伙伴

| 贸易伙伴 | 主要出口（→） | 主要进口（←） | 贸易平衡 |
|----------|--------------|--------------|:-------:|
| **须弥** | 地热电力、燃素制品、体育装备 | 算力服务、化工产品、生物医药 | 顺差 |
| **璃月** | 特种材料、竞技装备、温泉康养 | 机械装备、建材、精密仪器 | 基本平衡 |
| **枫丹** | 地热设备、龙伙伴装备、体育赛事 | 高端机械、精密电子、娱乐内容 | 逆差 |
| **稻妻** | 燃素燃料、体育装备、温泉技术 | 电子产品、电气设备、文化产品 | 顺差 |
| **蒙德** | 地热技术服务、龙伙伴 | 酒类、食品、风能技术 | 基本平衡 |
| **至冬** | 高能燃料、耐寒装备 | 冷链食品、矿产、工业机械 | 逆差 |

### 6.2 战略贸易路线

- **纳塔—须弥能源走廊**：多条超高压输电线路从回声之子共和国伸入须弥沙漠，输送地热电力。作为回报，须弥向纳塔提供算力支持、沙漠矿产和过境贸易便利。
- **暖泉港—枫丹航线**：纳塔最重要的海上贸易线，承担了联盟约 45% 的进口货物运输。
- **铁砧城—璃月铁路**：联盟对璃月贸易的核心陆路通道，年货运量超过 500 万吨。

## 七、龙伙伴经济链

龙伙伴（Saurian Companions）不仅是纳塔人的战斗伙伴和体育搭档，也构成了一个完整的经济生态：

1. **繁育与驯养**（悬木人共和国为主）：培育龙伙伴幼体，涉及基因选育、驯化训练和健康管理
2. **装备制造**（各共和国联合）：骑鞍、护甲、通讯器、健康监测设备——高端手工业与先进材料的结合
3. **医疗与保健**（烟谜主 + 流泉之众）：龙伙伴专属兽医体系，利用萨满医学和现代技术
4. **赛事经济**（全联盟）：龙伙伴竞速赛、越野赛、技巧赛等赛事体系
5. **旅游体验**（各共和国）：游客骑乘龙伙伴的体验项目
6. **龙伙伴出口**：具有血统认证的龙伙伴幼体出口至蒙德、璃月等国（受到严格的数量和健康管制）

龙伙伴经济链的年度总价值估计约 350 亿摩拉，直接和间接雇佣约 45 万人。

## 八、基础设施与要素禀赋

### 8.1 交通网络

- **公路**：联盟级主干道连接六共和国首府和圣火市，各共和国境内公路网覆盖率为 85%
- **铁路**：跨共和国铁路干线已全部实现电气化（依托地热电力），圣火市—铁砧城—沃原城高速铁路运营时速达 320 km/h
- **航空**：圣火市国际机场是联盟枢纽机场。各共和国首府均建有支线机场
- **港口**：流泉之众共和国的暖泉港为联盟最大商港，年吞吐量约 2,000 万吨

### 8.2 能源系统

- 全联盟电力由地热主导（~85%），其余来自小规模光伏（~10%）和风能（~5%）
- 联盟电网由「圣火电力调度中心」统一管理，各共和国电网互联互通
- 向须弥出口电力年收入约 80 亿摩拉

### 8.3 劳动力

- 总劳动力约 850 万人
