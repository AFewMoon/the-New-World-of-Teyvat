    须弥经济与产业概况

    货币说明：须弥国家银行发行的须弥卢比（SUR，1 摩拉 \(\approx\) 180 须弥卢比）为须弥法定货币。摩拉仍作为国际储备资产继续流通，但在须弥境内日常交易中已逐步被卢比取代。

    经济总览¶

    须弥社会主义联邦的经济格局呈现出鲜明的特色化偏科特征：在人工智能、虚空技术、生物科研和光伏能源四个特定方向上具有世界领先的科技实力，但现代工业体系则呈「有上游、无下游」的畸形结构——沙漠北邦的矿业采掘与初级冶炼、奥摩斯的基础石化、雨林北邦的农林产品加工虽具一定规模，但钢铁深加工、精密机械与装备制造、精细化工以及汽车与日用消费品制造等精深制造门类均薄弱且依赖进口。国土横跨东部雨林和西部沙漠两大截然不同的生态区域，形成了「雨林研发+沙漠能源」的双引擎经济格局。东部雨林区的须弥市以高等教育与前沿科研、人工智能与信息产业、现代生物育种与香料化工为核心；西部沙漠区则依托极端日照条件和广袤无人区，发展超大型太阳能光伏发电和绿色算力中心产业。两大区域的互补协同，使须弥在全球特定科技领域中占据不可替代的地位。

    宏观经济指标（参考值）：GDP 约 1,350~1,800 万亿须弥卢比，人口约 6,500 万，人均 GDP 约 2,077.2~2,768.4 万须弥卢比。通胀率约 1~3%，失业率约 3~5%。须弥在人工智能、虚空技术、生物科研和光伏能源四个方向上拥有世界领先的科技实力，但整体产业结构呈现明显的「高技术服务业强、制造业弱」的偏科格局——精深加工制品和日用消费品依赖进口，工业增加值在 GDP 中的占比低于璃月、枫丹和稻妻。人均产出虽位居提瓦特前列，但这一数字主要受高附加值 AI 服务贸易的拉动，掩盖了须弥在现代制造领域的结构性短板。

    优势产业¶

    高等教育与前沿科研¶

    教令院拆分后形成的多所部属高校（须弥科技大学、须弥民众大学、民族团结大学、须弥职业大学）承担着提瓦特最前沿的学术研究：

    • 元素生物学：须弥在元素生命体研究领域居于全球领先地位，雨林丰富的生物多样性为研究提供了天然实验室。
    • 量子通信：依托虚空系统的理论遗产，须弥在量子密钥分发和量子网络领域取得了突破性进展，与枫丹、璃月合作建设提瓦特首条跨国量子通信干线。
    • 材料科学与纳米技术：须弥材料研究所在仿生材料、纳米催化剂和智能响应材料领域成果卓著，成果广泛应用于医疗、能源和环境治理。
    • 国际学术交流：四所部属高校每年吸引来自蒙德、璃月、枫丹的大批留学生和访问学者，是提瓦特知识传播与人才流动的核心枢纽。

    人工智能与信息产业¶

    草元素力天然具有「记录」与「复苏」的属性——植物能够在元素力的引导下「记住」生长路径、「回忆」季节更替。须弥科学家通过对草元素力进行精密调制与高频编码，使其在神经网络推理、大规模知识图谱构建和智能涌现方面具备了其他元素力无法比拟的天然优势。这使得须弥在高端人工智能领域形成了近乎不可逾越的技术壁垒，垄断了全球高端信息产业从基础研发到终端部署的全流程，并在中端信息产业的产学研各环节占据主导地位。

    须弥人工智能产品现已形成完整的三层体系，均由须弥科技大学负责研发管理与技术迭代：

    产品 层级 上下文长度 性能定位 服务对象 商业模式
    努尔 (Nur) 高端 2 亿 超高吞吐效率、超低幻觉 仅供须弥联邦政府、各邦政府、各大单位使用 非商用，国家战略资源
    希克玛 (Hikma) 中高端 2 千万 综合性能均衡，逊于努尔 外国政府、企业，以及须弥国内个人与中小企业 商业出口 API 服务；敏感数据可储存在他国，但验算与缓存须保留在须弥国内
    卡拉姆 (Kalam) 中端 2 百万 性价比之选，正与他国尖端 AI 激烈竞争 全球开发者与企业 开源中端 AI，提供从 API 随买随用到私有化安装的全套服务
    • 努尔（「光」之意）是须弥最高级别的战略级人工智能，仅供须弥联邦政府、各邦政府及各大单位专用，不对外提供任何形式的商业服务。其超长上下文窗口与极低幻觉率，使其在国家治理、科研攻关和国防安全等关键领域发挥不可替代的作用。
    • 希克玛（「智慧」之意）是须弥对外出口创汇的核心产品线。各国政府和企业可通过 API 调用希克玛的强大能力，同时可以依法将敏感数据存储在本国境内，而模型验算与推理缓存则必须保留在须弥国内的指定算力中心。须弥国内的个人和中小企业亦可通过 API 使用希克玛，但优先保障外国政府及企业的服务容量。
    • 卡拉姆（「言语」之意）是须弥面向全球开源的中端人工智能。须弥提供从免费 API 配额、按量计费订阅、到私有化本地部署的全系列服务方案。基于卡拉姆开源模型的二次开发和微调生态正在提瓦特各国逐步形成。

    受限于须弥自身的工业与商业并不发达，缺乏丰富的制造、零售、物流等场景数据，须弥在小模型与场景特化 AI 领域的发展逊于枫丹、璃月、稻妻等国。这些国家凭借各自发达的垂直行业，在端侧推理、工业视觉质检、零售推荐系统等细分赛道上形成了差异化优势。

    上述三款人工智能均由须弥科技大学负责研发管理与技术迭代，须弥联邦政府虚空部负责技术监管——制定 AI 安全标准与出口管制政策，风纪委员会负责纪律监督——审查信息安全、AI 伦理与数据隐私保护。

    现代生物育种与香料化工¶

    雨林作为全球生物多样性热点地区，为须弥的生物技术产业提供了独一无二的资源基础：

    • 基因育种：利用雨林丰富的野生近缘种基因库，培育高产抗逆的小麦、水稻和经济作物品种。须弥的杂交水稻和耐旱玉米品种已在璃月、蒙德推广种植。
    • 天然香料提取：须弥香料以雨林特有的香辛料植物为原料，采用超临界 CO₂萃取和分子蒸馏等现代工艺，产品在提瓦特高端餐饮和香水工业中享有顶级品质声誉。
    • 生物制剂：开发微生物肥料、生物农药和酶制剂产品，推动绿色农业和可持续种植。

    超大型太阳能光伏发电（沙漠区）¶

    列柱沙原和千壑沙地是全球日照条件最优越的地区之一：

    • 集中式光伏电站群：须弥国有能源公司在沙漠腹地建设了提瓦特规模最大的光伏发电基地群，总装机容量位居七国之首。发出的清洁电力不仅满足须弥国内需求，还通过超高压输电网络向璃月、蒙德等邻国输送绿电（与枫丹的清洁能源合作以光伏面板出口和科研协作为主）。须弥与纳塔建立了双向电力互补机制——须弥沙漠光伏为纳塔高耗能冶炼产业提供白天的调峰电力，纳塔地热则在夜间为须弥算力中心补充基荷。
    • 光热发电：在千壑沙地建设了多座塔式光热电站，利用熔盐储热技术实现 24 小时连续发电，为沙漠算力中心提供稳定的基荷电力。
    • 光伏制造：须弥沙漠区建有大规模光伏面板制造工厂，产品除满足国内需求外，还出口至纳塔和枫丹。

    绿色算力中心（沙漠区）¶

    • 冷却方案与土地改良：沙漠算力中心采用海水淡化冷却闭环系统——通过管道从须弥南岸引取海水，经反渗透淡化后作为算力中心冷却用水，温排水经冷却塔降温后循环使用，部分浓缩盐水排入专设的蒸发池用于提取工业盐。淡化水在冷却循环中的损耗（约 15%）由持续引水补充，这部分淡水同时被用于周边沙漠土地的滴灌改良——在算力中心外围形成「冷却水-绿廊」系统，以淡化冷却水浸润沙漠，种植耐盐碱灌木和牧草，逐步将算力中心周边的荒漠改造为绿化带。这一方案兼具三重效益：利用海水资源解决沙漠冷却用水短缺、以冷却水余热促进冬季绿廊生长、通过绿化带阻隔风沙延长服务器设施寿命。综合 PUE（电能利用效率）可达 1.15 以下，显著优于提瓦特平均水平。
    • 客户集群：璃月金融数据处理中心、蒙德证券交易所灾备系统、枫丹影视渲染农场和稻妻游戏服务器均在须弥沙漠算力中心部署了大规模计算集群。
    • 云计算服务：须弥国家云计算平台为各国中小企业提供弹性计算、数据存储和 AI 训练服务，是提瓦特数字经济的算力基座之一。

    考古与探险旅游（沙漠区）¶

    • 赤王文明遗迹：千壑沙地分布着大量赤王时代的金字塔、神庙和地下陵墓，经修缮后对外开放。考古旅游是须弥沙漠区的重要外汇收入来源。
    • 绿洲文化与沙漠探险：阿如绿洲、辛赫绿洲等沙漠定居点保留了独特的沙漠文化和传统手工艺，沙漠越野、星空露营和骆驼商队体验项目深受蒙德、枫丹游客青睐。
    • 学术考古基地：须弥高校联盟在沙漠区设立了多个野外科考站，接待来自各国的考古学家和地质学家，形成了学术与旅游融合的特色生态。

    基础设施与要素禀赋¶

    • 交通：须弥的铁路和公路网络横跨雨林与沙漠两大区域。高速铁路连接须弥市与各邦首府城市，沙漠-雨林货运通道保障了光伏设备和算力中心物资的运输畅通。奥摩斯港是须弥最重要的国际贸易港口，连接枫丹和稻妻的海运航线。
    • 能源：沙漠区光伏电站是须弥的能源心脏，不仅满足国内电力需求，还向璃月、蒙德、枫丹出口清洁电力，并与纳塔建立双向互补机制（出口白天调峰电力、进口夜间地热基荷）。雨林区的水力发电站提供了稳定的补充电源。
    • 劳动力：须弥拥有提瓦特最高比例的科研人员和工程师人口。四所部属高校每年培养大量计算机、生物技术和能源工程领域的毕业生。沙漠区则以熟练的电力设施运维和工程施工人员见长。

    土地改革简史¶

    教令院时期的「学派领地制」与沙漠部族的边缘化 (TE 0~2005)¶

    在大革命前的漫长岁月中，须弥的土地制度呈现出雨林与沙漠的二元分化格局，与教令院六大学派的学术寡头体制深度绑定。雨林地区的土地名义上归教令院所有，实则由六大学派各自控制——明论派掌控须弥市周边的良田和果园，知论派把持奥摩斯港周边的商业用地，生论派则控制雨林腹地的药材种植区和生物研究基地。农民以「学田佃农」的身份耕种学派土地，需将收成的三至五成上缴学派，同时承担繁重的学派徭役——修路、建塔、为贤者宅邸服务。

    沙漠地区的情形截然不同。塔尼特部族、阿如绿洲居民等沙漠社群按照部落传统实行绿洲公地制——水源和可耕种的绿洲土地归部落集体所有，由部落首领和长老会共同分配使用权。但教令院的法律从未承认沙漠部落土地的合法所有权——在教令院的法典中，沙漠被划归为「未开发荒原」，沙漠部落被视为「无土地的流民」。这使得沙漠部落既无法在法律框架内保护自己的土地，也无法以土地为抵押获得信贷，实质上被排斥在须弥经济体系之外。沙漠部落与教令院之间围绕水源和绿洲的冲突绵延数百年，是须弥最深刻的社会矛盾之一。

    大革命与土地国有化 (TE 2005~2008)¶

    须弥大革命推翻了教令院千年统治后，新政权的第一项重大经济改革便是土地制度的彻底重构。革命政权在 TE 2005 年颁布《土地国有化法案》，宣布全部土地归国家所有，废除教令院学派对土地的一切控制权，同时宣布沙漠部落土地的合法所有权——以国家法律的形式首次承认了沙漠社群对其世代耕种的绿洲土地的权利。这一法案是「纳西妲主义」在经济领域的核心体现：土地不是任何个人或群体的私产，而是全民的共同财富，须由国家代表人民统一管理。

    六大学派控制的雨林良田和果园被全部没收，原「学田佃农」获得国家颁发的地权证书，成为土地国有框架下的永久使用权人。沙漠部落的传统领地被正式纳入国家土地登记体系，部落长老会获得国家授权的基层土地管理权。历时三年的土地国化和确权登记运动中，全国新增登记土地面积约相当于原有登记面积的一点五倍——绝大多数来自此前不被承认的沙漠部落领地。

    农业合作化与沙漠绿洲开发 (TE 2008~2018)¶

    土地国有化的实现，为须弥的农业合作化运动扫清了一切产权障碍。劳动党主导的农业合作化政策，将雨林地区分散的农户组织为大型农业生产合作社——农户保留土地永久使用权，但耕种计划、农资采购和产品销售由合作社统一管理。到 TE 2015 年，雨林地区约八成的耕地已纳入合作社体系，形成了规模化经营和机械化作业的基础。位于雨林东邦南部、由劳动党全国合作社联盟运营的现代农业合作社尤为典型——在这片约六千公顷的连片耕地上，合作化后的粮食产量较教令院时期提高了约两倍。

    沙漠区的绿洲开发进入了一个全新的阶段。国家投资在沙漠绿洲建设了现代化灌溉系统、温室大棚和农产品加工设施，使沙漠部落从自给自足的绿洲农耕转向面向全国市场的商品化农业生产。红砂绿洲的椰枣和香料、阿如绿洲的草药和水果，通过国家统一收购和物流体系进入须弥市和奥摩斯港的消费市场。沙漠区在合作化运动中保留了更多的部落自治空间——不同于雨林地区的大规模集中合作社，沙漠区普遍采用「部落合作社」模式，由部落长老会和合作社管理委员会双重领导。

    当代土地治理与工业用地矛盾（TE 2018 至今）¶

    随着须弥经济的重心逐步转向知识产业、算力服务和清洁能源，土地治理面临的矛盾也从「农业用地分配」转向了「工业与科研用地需求与农业及生态保护之间的冲突」。沙漠区超大型光伏电站和算力中心占用了大量沙漠土地，虽然这些土地此前几乎没有农业价值，但光伏面板阵列的遮光效应对绿洲周边微气候的影响、算力中心冷却用水的消耗量等问题，在须弥各界引发了持续讨论——科学联盟坚持「算力即国力」的开发立场，劳动党中的基层代表则呼吁保护沙漠部落的绿洲生态利益。截至 TE 2030 年，随着沙原三号、千壑四号等新一轮沙漠算力中心集群建成投运，算力用地与沙漠部落牧地、绿洲边缘的边界矛盾进一步显现。两党经联席会议协商，于 TE 2029 年推动出台《沙漠用地与算力发展协调办法》，将大型算力与光伏项目纳入用地指标统筹，并要求以「冷却水—绿廊」工程补偿周边荒漠化草地，作为「算力即国力」与绿洲生态保护之间的折中。

    须弥当代土地治理的另一个特征是知识产权的经济化为土地赋予了新的法律价值。教令院留下的丰厚学术遗产——包括虚空系统的传统知识产权和各类生物基因资源——在法律上被界定为「国家所有的知识性土地」，由须弥国家科学院统一管理，其商业开发和使用受《国家知识资产管理法》的规制。这一独特的制度安排，将须弥最宝贵的「知识财富」纳入了广义的土地治理体系。

    从整体上看，须弥的土地制度以大革命为分水岭，完成了从「学派领地制」到「国有化+永久使用权+合作化」的根本转变。与蒙德的农业主义保护或璃月的国资委主导不同，须弥的土地治理与社会主义意识形态和两党共同专政体制深度绑定——土地政策的走向始终在劳动党的「社会公平」诉求与科学联盟的「开发效率」主张之间寻找平衡。

    对外经济关系¶

    须弥主要出口 AI 算法与软件服务（含希克玛商业 API 输出与卡拉姆开源生态服务）、清洁电力、香料与生物育种技术、光伏面板和算力服务。人工智能 API 服务是须弥最重要的服务贸易出口项，希克玛面向外国政府和企业直接创汇，卡拉姆的开源生态与增值服务则持续提升须弥在全球 AI 市场的份额与影响力。主要进口精密机械 （枫丹）、半导体芯片 （稻妻）、基础消费品（璃月、蒙德）和能源勘探设备 （至冬）。至冬工业集团在重型勘探设备领域具有全球领先优势，须弥沙漠矿业和地热项目所需的高压钻井平台、地震勘探仪器均从至冬进口。须弥的 AI 技术和算力服务是璃月金融业数字化转型和枫丹影视渲染产业的关键支撑。须弥与纳塔在能源领域建立了成熟的双向电力互补机制——须弥沙漠光伏在白天为纳塔高耗能冶炼产业提供调峰电力，纳塔地热在夜间为须弥算力中心补充基荷，年度结算基本平衡。须弥与蒙德在风能技术研究和高校学术交流方面保持密切合作。

    意识形态维度¶

    须弥的社会主义体制使其在提瓦特大陆扮演着一个独特的「异类」角色。在枫丹的金融媒体和璃月的外交文件中，须弥常常被描述为「一个技术精湛但道路不同的国家」——这种措辞既是外交辞令，也折射出深层的不安。枫丹与璃月的商业精英阶层对须弥的两党共同专政和国有化体制持公开批评态度，认为其「以政治意志扭曲市场规律」；而须弥则反过来指责枫丹的金融垄断和璃月的资本势力为「新型殖民主义」。这种意识形态摩擦在日常交往中表现为：须弥出口的希克玛 AI 服务在枫丹和璃月被要求接受额外的「数据伦理审查」，须弥学者赴上述国家交流时面临更严格的签证审查，而须弥境内的外资企业在注册和经营范围上也受到比本土企业更严格的国民待遇审查。不过，双方都清醒地意识到彼此的经济高度互补——枫丹的精密机械和璃月的消费品是须弥无法自产的刚需，而须弥的 AI 和算力也是前者数字化转型的不可替代的支撑。这种「嘴上批判、手上合作」的格局，已成为提瓦特国际经济秩序中最微妙的一层底色。

    对幕府的 AI 与算力出口是这一格局的延伸。对幕府的出口是否正当，是须弥两党年度联合会议上反复出现的争论议题。须弥劳动党认为，幕府将须弥算力用于国家产业信息平台、AI 配给制和社员卡，构成对稻妻工人的压迫，主张收紧出口。须弥红色科学家联盟则辩称，对幕府出口既是希克玛迭代的试验场和数据来源，也是稳定可靠的创汇渠道；中断已签约的算力服务会损害须弥作为负责任技术供应国的国际观瞻。争论年复一年重提，两党都不让步，出口规模维持不变。
