> 注:本文档中的「TE」(Teyvat Era) 为提瓦特纪年缩写，以 TE 为统一纪年单位，记录[须弥](./须弥概况.md)从远古至今 (TE 2030) 的重大历史事件。[须弥](./须弥概况.md)社会主义联邦成立于 TE 2005 年大革命之后，直接沿用提瓦特纪元纪年，无独立纪年系统。全局性背景事件以「（背景）」标注。

## 大事年表

| 年份 (TE) | 事件 |
|:---------:|:----|
| **约 -500** | **（背景） 赤王阿赫玛尔接触禁忌知识**，花神牺牲撕开世界边界 |
| **约 -300** | **（背景） 三神王同盟**（赤王、花神、大慈树王）鼎盛 |
| **0** | **（背景） 魔神战争终结**，七神体系确立，大慈树王获草神之位 |
| **500** | **须弥教令院建立完整知识分类体系**，确立六大学派 |
| **1100** | **镀金旅团在沙漠地区崛起**，成为重要的跨境商旅武装护卫力量 |
| **1400** | **雨林扩张计划启动**——教令院运用虚空知识改良雨林生态 |
| **1500** | **（背景） 坎瑞亚灾变**——大慈树王与赤王相继消逝 |
| **1850** | 教令院启动虚空系统前身研究，知识数字化初现雏形 |
| **2002** | **（背景） 教令院改革，虚空系统重构**，智慧之城开启新时代 |
| **2005** | **大革命爆发**——秋，奥摩斯港工人罢工点燃革命导火索，一周内罢工浪潮席卷全国，沙漠部落武装同时向教令院驻军发起进攻；三个月后教令院宣布投降，六大学派被解散，千年学术寡头体制土崩瓦解；**《土地国有化法案》颁布**——全部土地收归国家所有，沙漠部落土地所有权首次获法律承认 |
| **2005~2008** | **土地国化和确权登记**——原「学田佃农」获得国家颁发地权证书，全国新增登记土地面积约相当于原有登记面积的 1.5 倍 |
| **约 2006** | **两党共同专政体制确立**——旧学派进步知识分子（红色科学家联盟骨干）与工农革命力量（劳动党前身）围绕建国路线辩论一年后，形成劳动革命党与红色科学家联盟长期联合执政的独特体制 |
| **2008~2018** | **农业合作化运动**——雨林地区农户组织为大型农业生产合作社，到 2015 年约八成耕地纳入合作社体系；沙漠区推行「部落合作社」模式，绿洲农业转向商品化生产 |
| **2012** | **（背景） [须弥](./须弥概况.md)卢比发行**，须弥国家银行运作 |
| **2016** | **（背景）** [须弥](./须弥概况.md)加入提瓦特财团联盟 (TFC)，成为首个后续加入的成员国 |
| **2018~2030** | **沙漠光伏与算力中心扩张**——列柱沙原、千壑沙地超大型光伏电站群与绿色算力中心建成，向璃月、[蒙德](../蒙德/蒙德综述.md)、[枫丹](../枫丹/枫丹综述.md)输送绿电，与[纳塔](../纳塔/纳塔综述.md)建立双向电力互补机制 |
| **2029** | **《沙漠用地与算力发展协调办法》出台**——大型算力与光伏项目纳入用地指标统筹，以「冷却水—绿廊」工程补偿周边荒漠化草地，作为「算力即国力」与绿洲生态保护之间的折中 |
| **2030** | **当前**——沙原三号、千壑四号等新一轮沙漠算力中心集群建成投运；两党共同专政体制稳固运作，[须弥](./须弥概况.md)在人工智能、虚空技术、生物科研与光伏能源四领域保持提瓦特领先 |

## 展望

| 纪年 | 事件 |
|:----|:----|
| **中长期** | **两党体制的长期稳定**——劳动革命党「社会公平」诉求与红色科学家联盟「开发效率」主张之间需持续协调 |
| **中长期** | **偏科式发展风险与区域差距**——精深制造依赖进口易受国际供应链波动影响，沙漠—雨林两地带发展水平差异显著 |
