> 注：本文档中的「TE」(Teyvat Era) 为提瓦特纪年缩写。以下纪年表以 TE 为统一纪年单位，记录提瓦特大陆从古至今的重大历史事件。
>
> 魔神战争结束于 TE 0（约 2000 年前）；坎瑞亚灾变发生于 TE 1500（约 500 年前）。

## 提瓦特通用纪年表

### 远古与魔神战争时期

| 年份 (TE) | 事件 |
|:---------:|:----|
| **约 -4500** | **葬火之战**——天理与原初龙王交战，天空岛对大陆掌控力下降，提瓦特进入动荡期 |
| **约 -1000** | **魔神战争爆发**——六十余位魔神为争夺七神席位展开千年混战，提瓦特大陆陷入空前战火 |
| **约 -700** | **归终与摩拉克斯结盟**，归离集文明进入鼎盛；**迭卡拉庇安**统治旧蒙德，以烈风筑墙 |
| **约 -600** | **起义军推翻高塔孤王**，巴巴托斯成为风神；北风狼王安德留斯放弃神位，力量注入大地 |
| **约 -500** | **归终陨落**，摩拉克斯率民南迁建立璃月港；赤王阿赫玛尔接触禁忌知识，花神牺牲撕开世界边界 |
| **约 -300** | **盐之魔神赫乌莉娅**陨落；**三神王同盟**（赤王、花神、大慈树王）鼎盛 |
| **约 -100** | 雷电姐妹统一稻妻诸岛，雷电真主文、雷电影主武；璃月港初具规模 |
| **0** | **魔神战争终结**——七位胜者获神之心，尘世七执政确立，TE 纪年自此零点起算 |

### 七神秩序时期

| 年份 (TE) | 事件 |
|:---------:|:----|
| **0** | **七神体系正式确立**——七国秩序奠定；七神于璃月聚会，象征新秩序建立 |
| **约 200** | **若陀龙王被封印**——摩拉克斯联合三位仙人将其封印于伏龙树下 |

| **400** | 稻妻**锁国令**初颁，雷电将军封闭诸岛（锁国政策于 TE 1500 年全面推行，TE 1700 年进一步强化） |
| **450** | **枫丹科学院事故**，引发枫丹社会对科技伦理的广泛辩论 |
| **500** | **须弥教令院**建立完整知识分类体系，确立六大学派 |
| **600** | **深渊灾厄**（杜林袭击蒙德），特瓦林与旅行者联手击败腐殖之龙 |
| **700** | **蒙德四风守护体系**确立，蒲公英骑士制度正式建立 |
| **1000** | **蒙德推翻旧贵族**——来自穆纳塔族的**温妮莎**领导人民起义，推翻以劳伦斯家族为首的腐朽统治；**西风骑士团**正式建立，温妮莎成为首任「狮牙骑士」，蒙德开启自由城邦新纪元 |
| **1100** | **镀金旅团**在须弥沙漠地区崛起，成为重要的跨境商旅武装护卫力量 |

| **1300** | **璃月七星**正式接管璃月港全部行政事务，仙人逐渐淡出日常治理 |
| **1400** | **须弥雨林扩张计划**启动，教令院运用虚空知识改良雨林生态 |
| **1500** | **坎瑞亚灾变**——位于须弥地下的无神国度坎瑞亚因过度发展深渊科技引发灾厄；天理维系者联合七神降临覆灭坎瑞亚，国民受诅咒，纯血后裔成「不死」诅咒者，余者化为丘丘人。连锁灾祸席卷七国：**雷电真**在坎瑞亚陨落，**雷电影**继位，稻妻转向「永恒」；**大慈树王**与**赤王**相继消逝；**冰之女皇**性情大变，暗启反抗天理之志 |

### 后坎瑞亚转型期

| 年份 (TE) | 事件 |
|:---------:|:----|
| **1520** | **愚人众执行官制正式组建**——至冬女皇以「执行官」为核心，组建横跨七国的情报与军事组织，暗中收集神之心 |
| **约 1530** | **层岩巨渊**因坎瑞亚灾变连锁反应，深渊侵蚀大规模爆发，璃月被迫全面关闭矿区，失去最重要的矿产来源 |
| **约 1550** | **纳塔巡夜者制度成型**——六部族正式确立以古名持有者为核心的巡夜者编制，深渊前线常态化防御体系建立 |
| **1600** | **至冬科学院**建立，系统化研究坎瑞亚机关术与提瓦特元素反应 |
| **约 1700** | **纳塔六部族联合首领制确立**——各部族首领正式组成常设议事机构，在外交与国防领域实现统一协调，为后世联盟体制奠定制度基础 |
| **1700** | 稻妻**锁国政策进一步强化**，外国商人被限制于离岛一隅 |
| **1750** | **蒙德风力发电技术萌芽**，星落平原首批风能实验设施建成 |
| **约 1800** | **至冬工业化启动**——冻土带石油天然气大规模开发，重工业体系成型 |
| **1800** | **枫丹科学院达到巅峰**，水压能源与精密机关制造领先七国 |
| **1850** | 须弥教令院启动虚空系统前身研究，知识数字化初现雏形 |
| **1900** | **蒙德风能开发起步**，星落平原首批规模化风力发电机组落成 |
| **1920** | **璃月矿冶技术升级**，层岩巨渊周边形成现代重工业区雏形 |
| **1950** | 蒙德星落平原风力发电场进入规模化建设阶段，成为提瓦特首个绿电基地 |
| **1960** | **至冬石油天然气管道网络**基本成型，辐射至冬全境及挪德卡莱 |
| **1970** | **纳塔地热技术突破**，火山地热发电站并网运行，高耗能特种材料产业兴起 |
| **1980** | **稻妻半导体产业起步**，踏鞴砂雷元素微雕刻蚀技术催生芯片制造雏形 |
| **1982** | **志飞联合制造集团公司成立**，七国政府联合持股，开启提瓦特航空工业全球化时代 |
| **1985** | **璃月工业化全面启动**——层岩巨渊矿区实现机械化开采改造，归离原工业区与黑岩厂冶金基地投产，璃月机车集团成立，铁路装备制造业进入现代阶段 |
| **1993** | **枫丹重建共和国成立**，社会秩序恢复，精密机械出口超越传统水压能源产业 |
| **1995** | **蒙德蒲公英酒业联盟完成产业整合**；**提瓦特大陆联合交易所成立**，各国骨干企业陆续上市 |
| **1998** | 多国开始筹建本币信用体系，摩拉通缩隐忧引发各国财政策略调整 |
| **1999** | 七国经济联系空前紧密，志飞系列客机全球机队规模突破 1500 架，跨境贸易额创历史新高 |

### 旅行者时代

| 年份 (TE) | 事件 |
|:---------:|:----|
| **2000** | **旅行者苏醒**，降临提瓦特大陆；**「送仙典仪」**——岩王帝君「遇刺」，璃月七星接管黄金屋，摩拉永久停铸 |
| **2001** | **蒙德「龙灾」终结**——旅行者击退被深渊腐蚀的风魔龙特瓦林，西风骑士团重建四风守护；**璃月七星全面执政**，仙人时代在璃月正式落幕 |
| **2002** | **稻妻锁国令松动、眼狩令废除**，雷电将军认知改变，稻妻向世界开放若干有限外贸窗口；**须弥教令院改革**，虚空系统重构，智慧之城开启新时代 |
| **2003** | **枫丹预言水灾**——枫丹社会秩序经历剧烈变动，发条机关与精密机械产业渡过危机 |
| **2004** | **纳塔深渊战争大规模爆发**，六部族全面反击 |
| **2005** | **纳塔深渊战争主力作战结束**，旅行者完成主线作战任务，深渊主力被击退；同一时期，摩拉停铸引发的通缩效应向全大陆扩散，各国加速寻求新一代货币方案 |

### 信用货币时代

| 年份 (TE) | 事件 |
|:---------:|:----|
| **2006** | 摩拉供需矛盾加剧，各国开始研究替代性货币方案 |
| **2008** | **至冬卢布率先发行**，至冬中央银行成立，拉开信用货币时代序幕（至冬自 2005 年起已率先启动本币体系研究，实际正式发行在 2008 TE） |
| **2010** | **璃月元**发行，璃月中央银行成立；**枫丹科朗**发行，枫丹重建共和国中央金库成立；**《铁路技术统一公约》签署**（统一标准轨距 1500 mm 与电气化供电制式） |
| **2011** | **蒙德镑**发行，蒙德中央银行成立 |
| **2012** | **须弥卢比、稻妻圆、纳塔鎏金币发行**；须弥国家银行、稻妻大藏省、纳塔中央银行相继运作；**提瓦特国际联盟 (ILT) 成立**；须弥启动虚空公共网络工程 |
| **2013** | **海祇元发行**，海祇岛自治领财政与经济部成立；须弥境内实现全境光纤覆盖，虚空公共网络向全体公民开放 |
| **2014** | **提瓦特刑事追捕协约 (TCPC) 缔约**；须弥开始向蒙德、璃月、枫丹等友好国家输出虚空技术与标准 |
| **2015** | **提瓦特财团联盟 (TFC) 成立**，总部设于璃月港；**提瓦特虚空联盟 (TAA) 成立**（总部设于须弥）；**现代化转型标志**——信用货币体系基本建成，七国从魔神战争遗留的「神铸经济」转向自主财政管理 |
| **2016** | **须弥加入 TFC**，成为首个后续加入的成员国；**枫丹—纳塔—须弥科技科研联盟 (FNS) 建立** |
| **2017** | **海祇岛自治领以观察员身份加入 TFC** |
| **2018** | **挪德卡莱以联系成员身份加入 TFC**——挪德卡莱以至冬卢布为境内法定货币，不设自主中央银行与主权货币，伏尼契商会承担事实上的货币兑换与调控职能；加入 TFC 后主要参与数据贸易结算框架与数字经济标准协调；**《提瓦特自由贸易与关税协定》(TFTTA) 签署**，七国缔约 |
| **2020** | **《跨境数据流动框架协议》签署**（[须弥](../../须弥/须弥概况.md)牵头，蒙德、璃月、稻妻、须弥、枫丹、纳塔六国缔约）；提瓦特各国进入经济调整期，信用货币体系覆盖全大陆 |
| **2021** | **[清籁岛](../../稻妻/清籁岛/清籁岛综述.md)社会主义革命爆发**，清籁岛人民政府成立；**《燃素开采与环境补偿框架协议》签署**（[纳塔](../../纳塔/纳塔综述.md)、[须弥](../../须弥/须弥概况.md)联合发起）；**纳塔六部族联合能源协议签署**，燃素管廊沿交通线位敷设 |
| **2022** | **《[提瓦特和平条约](../多边关系/提瓦特多边条约体系.md)》补充议定书**增补应对深渊异常事件的联合响应条款；**纳塔燃素城际线路投入试运行**，沿铁路线位实现能源网、信息网、交通网三网融合 |
| **2023** | **挪德卡莱数据自由港**全面运营，成为提瓦特数字经济中心 |
| **2025** | **《幕府与海祇岛和解备忘录》签署**，[海祇岛](../../稻妻/海祇岛/海祇岛综述.md)以自治领身份重返稻妻国；摩拉通缩持续深化，TFC 积极推进数字摩拉与成员国本币结算网络 |
| **2030** | **当前**——摩拉通缩持续深化，TFC 继续推进数字摩拉与成员国本币结算网络；提瓦特虚空联盟「全境互联」计划收官，全球覆盖率向 90% 目标冲刺 |
