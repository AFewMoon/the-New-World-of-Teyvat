# 提瓦特新世界

**The New World of Teyvat**

基于《原神》世界观的二次创作与深度世界构建项目。

---

## 简介

本项目尝试以虚构世界的政治学、经济学、历史学与社会学视角，对提瓦特大陆进行系统性的世界构建。内容涵盖蒙德、璃月、稻妻、枫丹、须弥、纳塔、至冬七大区域的政治体制、经济体系、历史沿革、地理区划、产业发展与军事力量等维度，旨在以写实笔触构筑一个逻辑自洽、细节丰满的提瓦特世界。

> ⚠️ **声明**：本项目为同人二次创作，基于《原神》（HoYoverse）的世界观背景。所有内容均为虚构，不代表任何现实政治立场。

## 内容概览

### 全局设定
| 文件 | 内容 |
|------|------|
| 历法体系：提瓦特纪元 | 提瓦特大陆的时间计算与历法系统 |
| 提瓦特航空概况 | 全大陆航空运输体系 |
| 提瓦特金融体系概况/概要 | 跨区域金融制度与经济运行 |
| 提瓦特现代产业体系 | 各区域产业分工与布局 |
| 玉衡之心，麒麟之契 | 璃月相关主题深度文章 |

### 蒙德
自由之城邦的政治体制、行政区划、经济地理与近现代史。

### 璃月
岩之国的政治体制、军事力量、交通网络（铁路与驿镖局）、能源路线历史大讨论以及汽车动力技术。

### 稻妻
分为幕府、海祇岛、清籁岛三大政治实体，各有独立的行政区划与政治体制概述。

### 枫丹
正义之国的行政区划、政治体制与经济产业概况。

### 须弥
智慧之国的政治体制、行政区划、高校体系与经济产业。

### 纳塔
战争之国的经济概况。

### 至冬
冰之国的经济概况。

### 政权关系
稻妻战争的历史分析以及《稻妻群岛与海祇岛和解备忘录》。
