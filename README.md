## 项目简介

### 构建理念

本项目尝试以**比较政治学、发展经济学与地缘政治理论**为方法论框架，对提瓦特大陆进行系统性的世界构建。不同于简单的设定罗列，项目致力于挖掘每个区域的内在逻辑——从政治体制的结构性设计、经济体系的内生矛盾，到历史变迁的因果链条，力求让每一个虚构设定都能经得起「如果这是真实世界，它应该如何运作」的推敲。

项目以《原神》游戏中的历史碎片、角色背景与地理设定为起点，在此基础上进行合理演绎与系统性扩展。例如：幕府与海祇岛之间的战争如何从宗教冲突演变为现代政治悲剧？璃月在帝君退位后如何从七星寡头体制过渡到人民民主？枫丹的「正义」理念如何在贵族共和制下落地——这些追问正是项目创作的出发点。

### 项目规模

- **国家/地区**：7 国 + 至冬治下的挪德卡莱自治地区（蒙德、璃月、稻妻、须弥、枫丹、纳塔、至冬）；
- **文档数量**：116 篇（持续增长中）；
- **文档类型**：政治概况（9 篇）、经济与产业概况（11 篇，含《至冬经济概况》）、军事概况（8 篇）、行政区划（8 篇）、综述/概况（10 篇）、政治简明读本（9 篇）、大事记（10 篇）、角色档案（2 篇）、专题研究（35 篇）、国际文件（12 篇：全球体系 6 / 多边关系 3 / 双边关系 3）、用户手册（1 篇）；
- **覆盖维度**：政治体制、经济体系、行政区划、军事力量、历史沿革、产业布局、金融货币、交通网络、信仰体系、多边治理、双边外交。

提瓦特世界的底层规则由六份全球体系文档搭建（位于 `国际/全球体系/`），涵盖历法、交通、金融、产业、武装力量及信息基础设施。`国际/多边关系/` 目录梳理国际组织、条约体系与全球治理议题；`国际/双边关系/` 目录深入剖析国家间政治经济互动。

### 📅 历法体系：提瓦特纪元

- **文档**：[国际/全球体系/历法体系：提瓦特纪元.md](./国际/全球体系/历法体系：提瓦特纪元.md)；
- **纪元起点**：魔神战争终结与七执政体系确立之年定为 **0 TE** (Teyvat Era)，TE 纪年自此零点起算。TE 纪年不仅是通用计时标准，更承载着对天理与七神秩序的历史敬畏。

## 七国详览

### ⚜️ 蒙德

**国名**：蒙德自由合众国 (Mondstadt Federal Republic)
**政体**：联邦制议会民主共和制 | **首都**：蒙德城

**政治体制**

蒙德是提瓦特西北部高度发达的民主联邦制国家。权力核心为联邦议会（下议院 200 席，上议院按各领名额分配），**工党、自由党、保守党**三大议会政党轮替或联合执政，议会外极左翼组织**蒙德无政府主义者—自由工人联盟 (MAFWA)** 以体制批判者身份持续在场。国家元首为礼仪性的联邦总统（由武装力量最高统帅——西风骑士团团长——自动兼任），政府首脑为联邦首相及其内阁，现任首相凯亚·亚尔伯里奇（工党党魁，TE 2027 年联合政府）。三级行政区划（领—市/区/军分区—乡/镇/警备区）构成治理骨架，其中「军分区」层级体现了蒙德对边境防御与冒险家管理的制度化安排；公民可经 5% 选民联署启动全民公投。

**经济体系**

- **清洁能源**：星落平原巨型风电群是提瓦特最主要的绿电输出地，风能技术世界领先；
- **酿酒与饮料工业**：蒲公英酒业联盟的瓶装酒畅销全大陆，「天使的馈赠」为提瓦特最具辨识度的酒类品牌；
- **生态农牧业**：大规模机械化种植与现代化牧场，提供优质的乳制品、小麦和农副产品；
- **低空经济**：滑翔翼运动与热气球观光，民用转化自西风骑士团「风之翼」滑翔翼特种部队技术；
- **铁路**：[蒙德铁路概况.md](./蒙德/蒙德铁路概况.md) 主干线由璃蒙铁路公司 (LMRC) 统营，MR 160 J 动力集中式动车组最高运行速度 200 km/h。

### 🪨 璃月

**国名**：璃月共和国 (Liyue Republic)
**政体**：总理内阁制的议会民主制（一党主导、多党竞争） | **首都**：璃港府

**政治体制**

「送仙典仪」后璃月步入人治时代，在原玉衡星刻晴与原天权星凝光的推动下，从七星寡头议政转型为共和国。**璃月人民党**自建国以来长期保持众议院多数并独立组阁，共和党、自由党、农会联盟、民主党四党在野参政。众议院（约 1,200 人，按人口比例直选）为国家最高权力机关，参议院（约 150 人，由众议院选举产生）为常设立法机关；国家主席为虚位元首（现任刻晴），政务院总理掌握行政实权（现任凝光）。监察院独立于行政体系，直接由众议院选举产生院长，负责监督全体公职人员的廉洁履职。意识形态以「节制资本、平均地权」的璃月特色民主主义为指导，武装力量由璃月人民党中央军事委员会绝对领导。

**经济体系**

- **国际金融与贸易**：璃月港是提瓦特最繁忙的深水港，承担国际贸易约半数以上的结算业务；璃月中央银行发行主权货币璃月元（MCY，1 摩拉 $\approx$ 0.85 璃月元）；
- **重工制造**：层岩巨渊统筹开采集团掌控最大综合性矿产基地，璃月机车集团总装重型工程机械与商用车辆；
- **铁路**：[璃月铁路概况.md](./璃月/璃月铁路概况.md) 璃月铁路总公司 (LRC) 运营，LR 系列动车组最高运行速度 240 km/h（预留 320 km/h），归离原—晨曦酒庄跨境连接蒙德；
- **能源大讨论**：[关于璃月能源路线的若干历史问题的决议](./璃月/关于璃月能源路线的若干历史问题的决议.md) 以决议形式系统总结三十年能源路线之争的历史与经验，展现国家转型期的思想碰撞与民主决策过程；
- **共和前后历史决议**：[关于共和前后的若干历史问题的决议](./璃月/关于共和前后的若干历史问题的决议.md) 以决议形式评价送仙典仪、摩拉停铸、轻策庄事件与宪政过渡等共和前后重大历史问题，记录七星寡头体制向共和体制转变的历史叙事；
- **大事记**：[璃月大事记](./璃月/璃月大事记.md) 以 TE/共和历双轨纪年系统梳理璃月从远古至今 (TE 2030) 的重大历史事件。

### ⚡ 稻妻

**国名**：稻妻群岛 (Inazuma Archipelago)
**政体**：三大政治实体并存——幕府君主立宪、海祇岛议会共和、清籁岛人民民主专政 | **首府**：稻妻城

**政治格局**

稻妻群岛呈现出提瓦特大陆最为复杂的政治格局——三股截然不同的政治实体在同一片群岛之上并存：

1. **幕府**（君主立宪制）：稻妻名义上的中央政权，正式国号为「稻妻王国」(Kingdom of Inazuma)。雷神雷电将军为国家元首并握最高决策权与军事统帅权，宰相为政府首脑；立法权归议事厅（资产选举制），中央行政由社奉行、天领奉行、勘定奉行三大机构执行。经济以**半导体与集成电路**（雷元素微雕刻蚀技术）、**消费电子终端**（智能留影机、通讯设备）、**文化出版与动漫游戏**（八重堂 IP 产业链）为三大支柱。
2. **海祇岛自治领**（议会制共和政体）：通过《幕府与海祇岛和解备忘录》确立的自治领地位，首府珊瑚宫镇。议会（153 席）为最高立法机构，执政长官任地区首脑，行政长官任政府首脑；拥有独立货币海祇元、武装力量（海祇岛自卫队）与外交自主权。独特的经济结构以**海洋生物制药**（珊瑚真珠深海药物）、**现代海洋产业**（深海养殖、海藻化工）和**高附加值农业**（鸣草改良经济作物）为特色。
3. **清籁岛**（社会主义人民民主专政）：清籁岛人民政府是稻妻群岛上第一个由工农群众当家作主的社会主义政权，稻妻工农革命党为唯一执政党，人民代表会议为最高权力机关。经济以铁矿、竹制品、制茶和药材加工为四大支柱。清籁岛的存在是稻妻战争遗留问题的结构性产物，也是群岛政治光谱上最鲜明的一极。

### 📚 须弥

**国名**：须弥社会主义联邦 (Sumeru Socialist Federation)
**政体**：社会主义联邦制——两党共同专政 | **首都**：须弥城

**政治体制**

须弥横跨东部雨林与西部沙漠，由须弥劳动革命党与须弥红色科学家联盟两党长期联合执政、互相监督，以「纳西妲主义」为指导思想。全国民众代表大会（约 800 名代表，一院制）为最高权力机关，总统纳西妲为国家元首，总理领导须弥人民委员会。旧教令院被拆分为三所顶层科研机构与四所部属高校，实现治学、工程、行政三权分离。三级行政区划（邦/直辖市—市/县—乡/镇）与基层群众自治相结合。

**经济体系**

须弥经济形成独特的**双引擎格局**：

- **雨林区**：以高等教育与 AI 科研为核心，四所部属高校涵盖研究型（须弥科技大学）、应用型（须弥民众大学）、综合型（民族团结大学）和职业型（须弥职业大学）四大方向；虚空系统的民用化为各国提供 AI 算法与云计算服务；
- **沙漠区**：列柱沙原超大型太阳能光伏电站群为提瓦特规模最大的集中式光伏基地，沙漠绿色算力中心利用极端日照与夜间低温降低能耗。

### ⚖️ 枫丹

**国名**：枫丹重建共和国 (Fontaine Restored Republic)
**政体**：贵族共和制 | **首都**：枫丹廷

**政治体制**

枫丹实行独特的贵族共和制——并非普选民主意义上的共和，而是精英共和。最高评议会（约 200 席）为最高立法与决策机构，由豪门家族代表、行业协会总长、刺玫会代表与水神任命的独立评审组成，席位按人口、经济影响力与国家战略契合度每四年核定。贵族分为五等——公、侯、伯、子、男——每一等级对应不同的政治权利与义务。水神芙卡洛斯为象征性国家元首（「神权虚悬、实权归官」），最高审判官那维莱特兼任行政与司法两大系统的最高领导。治理特色在于**基层治理外包**：不设统一的基层行政组织，而是将职能委托给家族领地管理机构、行业协会或刺玫会支部。欧庇克莱歌剧院作为最高评议会所在地，同时也是提瓦特最高仲裁法院所在地。

**经济体系**

枫丹经济以四大支柱闻名：

1. **高端精密机械与机器人**：发条机关民用化与自动化产线，枫丹工程院领导技术研发；
2. **法律仲裁与知识产权服务**：为提瓦特各国提供跨国仲裁和知识产权保护；
3. **时尚奢侈品与美妆**：黎翡大区香水与枫丹廷时装沙龙引领提瓦特衣着风尚；
4. **影视娱乐工业**：《蒸汽鸟日报》等传媒集团与枫丹映影工作室构成提瓦特最发达的影视制作体系。

### 🔥 纳塔

**国名**：纳塔联盟 (Natlan Union)
**政体**：六共和国组成的超国家联合体 | **首府**：圣火市

**政治体制**

纳塔联盟位于提瓦特西南部，由六个共和国——**回声之子、流泉之众、悬木人、花羽会、沃陆之邦、烟谜主**——组成的超国家联合体。六共和国各自拥有独特的政治体制（酋长议会制、贤者会议制、体育议会制等），将外交、国防、货币发行与古名信仰管理让渡于联盟。《圣火盟约》为宪法基础，联盟总统由全民直选产生，任期六年（现任玛薇卡）。

**核心特色**

- **古名信仰**：[古名与还魂诗](./纳塔/古名与还魂诗——纳塔传统信仰体系.md) 深入剖析了这一古老灵魂信仰的哲学根基——「古名」是纳塔人死后留在世上的精神印记，还魂诗则是召唤古名回归的祭祀仪式；
- **经济**：地热能源开发、极限体育与电竞产业、燃素相关特种新材料、温泉康养旅游；
- **燃素城际线路**：沿高铁线位敷设燃素管廊，实现「能源网+信息网+交通网」三网融合；
- **游隙灵道系统**：基于燃素流动形成的空中能量通路，城市间列车磁导向悬浮行驶，最高速度可达 180 km/h；
- **铁路**：[纳塔铁路概况.md](./纳塔/纳塔铁路概况.md) 纳塔铁路联盟 (NRU) 统一管理高铁，NR 系列动车组最高运行速度 210 km/h。

### ❄️ 至冬

**国名**：至冬国 (Snezhnaya)
**政体**：高度集权的工业强国 | **首都**：至冬宫

> 📁 至冬经济、能源与军事档案位于 `至冬/` 目录：[至冬经济概况](./至冬/至冬经济概况.md)、[至冬能源概况](./至冬/至冬能源概况.md)、[至冬军事概况](./至冬/至冬军事概况.md)。

**经济体系**

严酷的冻土环境催生了至冬独特的四大经济支柱：

- **军工与航空航天**：提瓦特技术最完备的重型武器制造体系与极地航天发射能力，极地发射场具备独特的轨道入轨优势；
- **化石能源开采**：冻土带下蕴藏提瓦特最大规模的油气储量，跨境管道向蒙德和璃月出口天然气；
- **极地科考与破冰船制造**：全球领先的极地科考能力，核动力破冰船设计与建造工艺世界一流；

**金融体系**

- **至冬卢布**（SNR，1 摩拉 $\approx$ 0.71 至冬卢布）：至冬全境法定货币；
- **北国银行**：提瓦特最具影响力的跨国金融机构之一，专司跨境结算与国际金融服务，总部设于至冬宫，在璃月港金融区设有最大的外资分行，与至冬中央银行形成市场分立格局，深度参与各国基建投资与产业并购。

### 🏔️ 挪德卡莱

**地区**：挪德卡莱（Nod-Krai，至冬国自治领地）
**政体**：11 股势力割据的**联合政府** | **核心首府**：那夏镇

**政治生态**

挪德卡莱是至冬国南端面积广阔、至冬仅保留领土诉求的化外之地。这里没有狭义上的中央政府——**挪德卡莱联合政府**由 11 股势力平等组建，是实际上的最高权力机关，管辖范围覆盖以那夏镇为中心的统辖区域（约 1,360 km²）。出了统辖区域，便是各方势力割据的控制区与不承认任何政府权威的无政府地带。

**核心资源：月矩力（涅法海姆）**

月矩力是三位月神陨落后残留在大地上的古老神力，也是挪德卡莱一切争端的根源。它是七元素的原始形态，能量密度极高、远超元素结晶，对深渊能量具有天然中和作用。低纯度矿石市场价约 500~1,000 SNR/kg，高纯度凝晶可达 50,000~150,000 SNR/kg。

**主要势力**

| 势力 | 定位 | 控制区域 | 核心诉求 |
|------|------|---------|---------|
| **霜月之子** | 本土宗教团体 | 希汐岛 | 守护月神纯正信仰，抵抗月矩力掠夺性开采 |
| **执灯人** | 古老守护者组织 | 皮达米拉地区 | 抵御狂猎和深渊侵蚀 |
| **愚人众** | 至冬官方军事/科研力量 | 月矩力实验设计局 | 执行「苍星圣敇」——谋取月之力量 |
| **伏尼契商会** | 神秘商业/情报组织 | 那夏镇秘闻馆 | 维护商业秩序，充当各方沟通桥梁 |
| **西风骑士团远征军** | 蒙德军事力量 | 安瓦蒂尼尔湖 | 监测深渊能量异常 |
| **蛋卷工坊** | 天才机械工坊 | 那夏镇西侧 | 奇思妙想的发明创造 |
| **魔女会（北境花园）** | 远古智慧组织 | 北境花园（幻术隐藏） | 与世界本源相关的深层研究 |
| **盗宝团（发源地）** | 盗贼互助组织 | 活动遍布全境 | 寻找「雷德·米勒」的伟大财宝 |
| **雪国妖精** | 没落古代精灵族 | 深山密林与古老遗迹 | 族群存续与未来抉择 |
| **狂猎** | 深渊幽魂大军（天灾） | 极北冻土边缘 | 无意识自然现象 |
| **冒险家协会** | 冒险家互助组织 | 那夏镇分会 | 为冒险家提供支持与服务 |

**经济体系**

挪德卡莱的经济是月矩力开采、贸易、自给农业与掠夺经济的混合体。伏尼契商会实际主宰经济命脉——秘闻馆同时扮演中央银行、情报交易所和地下金融中心的角色。总人口约 271 万（含驻军），年经济总量约 310 亿至冬卢布，人均 GDP 约 11,400 SNR（统辖区域人均约 16,000 SNR）。

农业自给率约 90%，由霜月之子的绿色畜牧业（银月奶酪、极地绿色牧产）与执灯士的屯田体系（寒地黑麦、温室种植）构成双层产出结构。

## 政权关系与地缘政治

### 稻妻战争与和平

幕府与海祇岛之间的战争是提瓦特当代史上最重要的地缘政治事件之一。**《幕府与海祇岛和解备忘录》**确立了停火与非军事区划定、海祇岛自治领的地位分野，以及双方在主权承认问题上的妥协方案。

**《稻妻战争的双面镜像：从大蛇东征到海祇岛和解的政治悲剧与和平探索》**以双重叙事结构深入剖析了这一冲突：从大蛇东征的神话起源到现代政治博弈，从幕府的锁国立场到海祇岛的自决诉求，揭示了超越善恶二元论的政治悲剧复杂性。该文档是理解稻妻群岛当代政治格局的核心文本。

**专题文档**：[国际/双边关系/幕府—海祇岛关系.md](./国际/双边关系/幕府—海祇岛关系.md) 从和解备忘录签署后的博弈视角，深入分析冷和平状态下的利益交换与制度摩擦。

### 货币主权与国际秩序

摩拉在帝君退位后的停铸引发了提瓦特金融体系的根本性变革：

- 各国脱离摩拉本位制，陆续发行主权信用货币；至冬卢布、璃月元等货币的出现标志着「后摩拉时代」的到来；
- 摩拉从唯一国际通货转型为国际储备资产与大宗商品结算的锚定媒介；
- 汇率浮动与货币主权成为地缘政治博弈的核心议题——各国央行在合作与竞争之间寻找平衡；
- 北国银行（至冬）与璃月中央银行分别代表了「跨国金融扩张」和「贸易金融枢纽」两种不同的金融国际化路径。

### 挪德卡莱——提瓦特的「巴尔干」

挪德卡莱的独特地位使其成为提瓦特地缘政治中最复杂的热点：

- **名义上**：至冬宣示主权，称其为「自古以来不可分割的自治领土」；
- **实际上**：至冬控制力仅限于愚人众驻地和月矩力实验设计局，联合政府由 11 股势力平等组建；
- **国际承认**：其他国家私下将联合政府视作挪德卡莱的实际治理机构，但官方层面沿袭至冬的「自治领地」说辞；
- **核心矛盾**：月矩力资源的争夺与各方势力在联合政府框架内外的博弈。

**专题文档**：[国际/双边关系/至冬—挪德卡莱关系.md](./国际/双边关系/至冬—挪德卡莱关系.md) 深度剖析宗主—自治领之间的非对称权力格局与经济纽带。

### 璃月—蒙德深度一体化

璃月与蒙德之间已形成超越一般自由贸易框架的超国家开放机制——资本、技术与劳动力自由流动，蒙德镑以 1:5 的固定汇率与璃月元单方面挂钩，构成货币主权的实质性让渡。该模式为提瓦特区域一体化提供了实验样本。

**专题文档**：[国际/双边关系/璃月—蒙德关系.md](./国际/双边关系/璃月—蒙德关系.md) 系统梳理经济合作、政治协调与安全协作的全景。

### 璃月能源路线之争

璃月内部关于能源发展路线的三十年大讨论，已由璃月人民党中央委员会以《关于璃月能源路线的若干历史问题的决议》的形式作出历史总结，是理解璃月当代政治民主决策过程的窗口。争论焦点围绕：是依托传统符箓与元素动力技术走自主创新路线，还是引入至冬或枫丹的成熟技术体系加速工业化。这场大讨论最终以「技术自主优先、多元能源并进」的共识告一段落，深刻影响了璃月铁路电气化、汽车动力路线和重工业布局。

### `fix_punctuation.py` — 文本规范化工具

对仓库中所有 Markdown 文件执行统一的标点符号与格式规范化处理，保障各区域文档的书写风格一致。具体操作包括：

| 功能 | 说明 | 示例 |
|-----|------|------|
| **中文引号替换** | 英文单双引号 → 中文引号 (「」「『』」) | `"背景"` → `「背景」` |
| **数字间连字符** | 数字之间的 `-` 统一为 `~` | `45%-50%` → `45%~50%` |
| **数字/中文/英文间距** | 数字与非数字、中文与英文间补足/规整空格 | `郡GDP` → `郡 GDP`，`GDP的` → `GDP 的` |
| **加粗标记空格** | `**` 内部紧贴内容，外部依相邻字符自动补空格 | `的**30%**` → `的 **30%**` |
| **标题序号删除** | 移除 `## 一、背景` 中的中文/数字序号 | `## 一、背景` → `## 背景` |
| **保护机制** | 代码块、行内代码、Markdown 链接/图片中的 URL 编码不受任何正则操作影响 | 原样保留 |

**使用方式**（所有命令从 `tools/` 目录运行）：

```powershell
cd tools
& "C:\Program\anaconda3\python.exe" fix_punctuation.py                 # 全量格式化
& "C:\Program\anaconda3\python.exe" fix_punctuation.py --check         # CI 只读检查
& "C:\Program\anaconda3\python.exe" fix_punctuation.py --files 文件.md  # 处理单个文件
```


### `tools/local/` — 本地 Obsidian 转换层 (gitignored)

> **仓库规范格式为标准 Markdown 链接 `[text](页面相对路径.md)`**，链接以**当前文件所在目录**为基准解析（MkDocs 规则）：目标与文件同目录用 `./xxx.md`，跨目录用 `../目录/xxx.md`。所有协作者 (VS Code / Typora / GitHub Web) 直接读写，无需任何转换。仅 Obsidian 用户在本地做透明的 wikilink ↔ MD link 切换。

Obsidian 用户首次使用前安装 git hooks：

```powershell
.\tools\local\install-hooks.ps1
```

安装后自动：`git pull` / `git checkout` 时 MD links 自动转为 wikilinks（Obsidian 可读）；`git commit` 时 wikilinks 自动转回 MD links 后再入库。

### CI/CD 流水线

- **`.github/workflows/lint.yml`**：push/PR 时运行 `fix_punctuation.py --check` + `concept_linker.py --ci`；PR 失败时 bot 自动修复并回推；
- **`.github/workflows/deploy.yml`**：push 到 `master` 时构建 MkDocs 并部署 GitHub Pages。

|---|---|---|
| **清华 TUNA** | `https://pypi.tuna.tsinghua.edu.cn/simple/` | 社区首选，同步及时 |

临时使用（单次安装生效）：

```powershell
python -m pip install 包名 -i https://pypi.tuna.tsinghua.edu.cn/simple/
```

永久设置（写入 `%APPDATA%\pip\pip.ini`）：

```powershell
python -m pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple/

```

## 文档约定

### 货币说明块

各国家/地区的经济文档首行统一以 `> **货币说明**` 开头，格式如下：

```
> **货币说明**：[国家名][中央银行/发行机构]发行的**[币种名称]**（[币种代码]，[汇率说明]）为[使用范围]法定货币。[其他货币]仍作为国际储备资产继续流通。
```

### 数据表格风格

- 经济数据表格统一使用居中对齐 (`:---:`) 的 Markdown 表格；
- 货币数据保留一位或两位有效小数，不精确至整数；
- 大额数据使用「约」「估算」等限定词标注不确定性。

### 文档命名规范

- 目录名统一使用国家/地区中文名称（如 `蒙德/`、`挪德卡莱/`、`至冬/`）；
- 稻妻内部按政治实体分三级子目录：`幕府/` `海祇岛/` `清籁岛/`；
- 文件名格式为 `[区域]政治概况.md`、`[区域]政治简明读本.md`、`[区域]经济与产业概况.md`、`[区域]行政区划.md`、`[区域]综述.md`；
- 目录命名规则：涉及多个政权的文件用 `稻妻` 前缀（如 `稻妻经济与产业概况.md`），仅涉及单一政权者用对应前缀（如 `幕府政治概况.md`）；
- 国际文件体系分为三个子目录：`国际/全球体系/` 存放跨区域系统文档，`国际/多边关系/` 存放多边治理文档，`国际/双边关系/` 存放双边关系专题；
- 双边关系文档命名格式为 `[国度A]—[国度B]关系.md`（如 `璃月—蒙德关系.md`）；
- 专题文档使用全称完整标题（如 `稻妻战争的双面镜像：从大蛇东征到海祇岛和解的政治悲剧与和平探索.md`）。

## 贡献指南

欢迎对项目提出改进建议。如需贡献新内容或修正现有设定，请遵循以下原则：

1. **保持统一风格**：新文档应遵循上述文档约定，包括货币说明块、数据表格格式和命名规范；
2. **尊重已有设定**：跨区域内容（如国际关系、金融体系、交通网络）应与核心设定文档保持一致；如发现文档间口径冲突，优先以 `国际/全球体系/` 下对应文档为准；
3. **基于游戏原设**：衍生创作应以《原神》游戏中的历史碎片、角色背景与地理设定为合理起点；
4. **提交方式**：请通过 GitHub Issues 或 Pull Requests 提交修改建议。对于较大的新增内容，建议先开 Issue 讨论设定方向；
5. **概念链接**：如有新增概念或文件，请运行 `concept_linker.py` 注入 wikilink（`--refresh` 或 `--scan-only` 后手动确认映射）；
6. **格式处理**：提交前请运行 `fix_punctuation.py` 工具确保标点与格式规范一致。
