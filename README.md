## 项目简介

本项目尝试以虚构世界的政治学、经济学、历史学与社会学视角，对提瓦特大陆进行系统性的世界构建。内容涵盖**蒙德、璃月、稻妻、须弥、枫丹、纳塔、至冬**七大区域的政治体制、经济体系、历史沿革、地理区划、产业发展等维度。从蒙德的议会民主联邦制、璃月的新民主主义共和制，到枫丹的贵族共和制、须弥的社会主义联邦制，再到稻妻群岛内幕府君主立宪、海祇岛议会共和、清籁岛人民民主专政三种体制并存的独特格局，项目展示了丰富的政治光谱。纳塔的超国家联合体与至冬的冻土工业帝国，则分别代表了联邦制的另一种可能方向与极端环境下的重工业发展模式。各国发行主权信用货币，摩拉从唯一的国际通货转型为储备资产，汇率浮动与货币主权成为核心议题——这一独立的经济金融体系是世界观构建的重要基石。

> ⚠️ **声明**：本项目为同人二次创作，基于《原神》（HoYoverse）的世界观背景。所有内容均为虚构，不代表任何现实政治立场。

## 全局设定

提瓦特世界的底层规则由四份核心文档搭建。**《历法体系：提瓦特纪元》**以魔神战争终结与七执政体系确立为纪元起点（1 TE），详细说明大陆的时间计算方式与纪年规则；TE 纪年不仅是通用计时标准，更承载着对「天理」与「七神」秩序的历史敬畏。**《提瓦特航空概况》**以璃月「志飞联合制造集团公司」为主角，梳理志飞系列客机的型号谱系、技术参数与航线网络，展现经济全球化在航空领域的缩影。**《提瓦特金融体系概况》**及配套的概要版本，横跨数千年货币金融史——从摩拉的黄金时代（帝君亲手铸造、兼具通货与炼金介质双重属性），到帝君退位后各国主权信用货币的发行与多元格局，再到摩拉通缩、汇率波动、货币主权等当代挑战。**《提瓦特现代产业体系》**则全景展示七国各区域的优势产业布局，揭示基于元素特质与地理环境的差异化「生态位」。

## 七国详览

### ⚜️ 蒙德

蒙德自由合众国是提瓦特西北部一个高度发达的民主联邦制国家。议会民主制之下，四大政党——无政府主义者—自由工人联盟、保守党、自由民主党、绿党——在议会中角逐，体现自由与秩序的动态平衡。三级行政区划（领—市/区/军分区—乡/镇/警备区）构成了治理骨架。经济以风能清洁能源闻名，星落平原数以万计的巨型风力发电机组是提瓦特最主要的绿电输出地；现代酿酒与饮料工业依托蒲公英、葡萄等优质农产品畅销全大陆；生态农牧业与低空经济（滑翔翼、热气球）也是重要的产业支柱。政治简明读本提供了面向公民的权力结构与选举规则解读，而《蒙德新世纪史（节选）》更深入描绘了游吟诗人温迪所代表的无政府主义思潮如何在知识分子与底层民众中传播，重新塑造了蒙德精神。

### 🪨 璃月

璃月共和国在「送仙典仪」后步入人治时代。经过三十年工业革命与社会阶层分化，从七星寡头议政转型为新民主主义共和国。璃月人民党领导下的多党合作与政治协商制度，配合国资委对核心命脉产业的掌控，形成了独特的国家治理模式。经济以国际贸易与金融为龙头、重工制造为基石。铁路网络覆盖 64 万平方公里国土，高速铁路连接五大城市枢纽；从传统江湖镖局转型而来的驿镖局联盟成为国家物流动脉。《璃月汽车动力技术》介绍了以元素力为核心的多元动力技术路线，《三十年论战》则回顾了工业化初期围绕能源路线展开的长达三十年的全民大讨论与最终抉择。《促进共同发展》一文阐述了新民主主义阶段从「先富」到「共富」的区域协调发展方针。

### ⚡ 稻妻

稻妻群岛呈现出提瓦特大陆最为复杂的政治格局——三大政治实体并存：

**幕府**实行君主立宪制，保守党、自由党、社会民主党等主要政党在议会中博弈，在锁国传统与开放浪潮之间寻找平衡。经济以半导体与集成电路、消费电子、文化出版与动漫游戏为支柱，经历了从锁国体制向开放经济的深刻转型。

**海祇岛**以高度自治的议会制共和政体运作。执政长官为国家元首，行政长官为政府首脑；《和解备忘录》确立了重返稻妻国框架下的「一国两制」格局。海洋生物制药依托珊瑚海独特生态研发高端药物与抗衰老医美原料，现代海洋产业覆盖深海网箱养殖、海藻化工与深海科考旅游，鸣草等特色高附加值农业是出口创汇的重要增长极。

**清籁岛**是提瓦特大陆上唯一一个社会主义人民民主专政政权。工农革命党以枫原万叶思想为指引，从「火花俱乐部」的读书会起步，经武装起义夺取政权，建立起人民代表会议制度。在幕府的经济封锁下，清籁岛推行土地改革与计划经济体制，铁矿开采、竹制品加工、制茶和药材加工为四大支柱产业。战时状态下的全民皆兵体制与「工农夜校」等文化扫盲运动，勾勒出一个在战火中重建的社会主义社会的独特面貌。

### 📚 须弥

须弥社会主义联邦横跨东部雨林与西部沙漠。纳西妲主义的劳动革命党与红色科学家联盟两党共同专政，草神纳西妲担任总统与两党共同名誉主席。旧教令院被拆分为三所顶层科研机构与四所部属高校，实现「治学、工程、行政」三权分离。经济上形成独特的双引擎格局——雨林区以高等教育与 AI 科研为核心，沙漠区则发展超大型太阳能光伏与绿色算力中心。三级行政区划（邦/直辖市—市/县—乡/镇）与基层群众自治相结合，体现了联邦制下的治理特色。

### ⚖️ 枫丹

枫丹重建共和国实行独特的贵族共和制。在预言水灾的废墟上，由豪门家族、行业协会与平民力量共同缔造了「正义」「契约」「荣耀」的核心理念。治理体系的一大特色是基层治理外包——不设统一的基层行政组织，而是将治理职能委托给家族领地管理机构、行业协会、堂区或刺玫会支部。元老院与平民院形成权力制衡，贵族分为公爵、侯爵、伯爵、子爵、男爵五个等级。经济上以高端精密机械与机器人、法律仲裁与知识产权服务、时尚奢侈品与美妆、影视娱乐工业为四大支柱，海洋工程与水产经济同样发达。

### 🔥 纳塔

纳塔联盟位于提瓦特西南部，与须弥沙漠接壤，是一个由六个共和国组成的**超国家联合体**。全国以活跃的火山地貌、广袤的熔岩平原和高原温泉带为特征，面积约 86 万平方公里，人口约 1560 万。六共和国——回声之子、流泉之众、悬木人、花羽会、沃陆之邦、烟谜主——各自拥有独特的政治体制（酋长议会制、贤者会议制、体育议会制等），并将外交、国防、货币发行与古名信仰管理四项核心主权让渡于联盟。《圣火盟约》为联盟宪法基础，联盟总统由全民直选产生，任期六年；联盟代议院实行双轨代表制（人口比例代表与共和国均等代表并行）。首都圣火市为联盟直辖地。

### ❄️ 至冬

至冬位于提瓦特极北之地，国土以严寒冻土带、广阔针叶林区和漫长极地海岸线为特征，严酷环境塑造了坚韧不拔的民族性格与庞大的重工业体系。至冬的主要出口产品为油气资源、军工装备、冷冻食品、破冰船和冰雪运动装备；主要进口产品为精密电子元件（稻妻）、消费品（璃月轻工、蒙德食品饮料）、高端机械（枫丹）和生物医药产品（海祇岛）。

## 政权关系

幕府与海祇岛之间的《和解备忘录》是提瓦特当代史上最重要的政治文件之一。它确立了停火与非军事区划定、海祇岛自治领的地位分野，以及双方在主权承认问题上的妥协方案。对于这一历史进程，《稻妻战争的双面镜像》以双重叙事结构深入剖析了从大蛇东征到海祇岛和解的政治神学、祟神诅咒的遗毒，以及超越善恶二元论的政治悲剧复杂性。
