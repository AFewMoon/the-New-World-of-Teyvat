## 项目简介

### 构建理念

本项目尝试以**比较政治学、发展经济学与地缘政治理论**为方法论框架，对提瓦特大陆进行系统性的世界构建。不同于简单的设定罗列，项目致力于挖掘每个区域的内在逻辑——从政治体制的结构性设计、经济体系的内生矛盾，到历史变迁的因果链条，力求让每一个虚构设定都能经得起「如果这是真实世界，它应该如何运作」的推敲。

项目以《原神》游戏中的历史碎片、角色背景与地理设定为起点，在此基础上进行合理演绎与系统性扩展。例如：幕府与海祇岛之间的战争如何从宗教冲突演变为现代政治悲剧？璃月在帝君退位后如何从七星寡头体制过渡到人民民主？枫丹的「正义」理念如何在贵族共和制下落地——这些追问正是项目创作的出发点。

### 项目规模

- **国家/地区**：8 个（蒙德、璃月、稻妻、须弥、枫丹、纳塔、至冬、挪德卡莱）
- **文档数量**：60+ 篇（持续增长中）
- **文档类型**：政治概况（8 篇）、经济与产业概况（8 篇）、行政区划（6 篇）、综述/简明读本（12 篇）、专题研究（10+篇）、角色档案（2 篇）、跨区域概览（5 篇）
- **覆盖维度**：政治体制、经济体系、行政区划、历史沿革、产业布局、金融货币、交通网络、信仰体系

## 核心设定

提瓦特世界的底层规则由七份跨区域核心文档搭建，涵盖历法、交通、金融、产业、信息基础设施及专题区域研究。

### 📅 历法体系：提瓦特纪元

- **文档**：[国际/历法体系：提瓦特纪元.md](./国际/历法体系：提瓦特纪元.md)
- **纪元起点**：魔神战争终结与七执政体系确立之年定为 **1 TE** （Teyvat Era）。TE 纪年不仅是通用计时标准，更承载着对天理与七神秩序的历史敬畏。
- **核心意义**：历法体系是提瓦特世界全部政治、经济叙事的时间坐标，各区域的历史事件均以此纪年统一对齐——例如帝君「假死」退位发生于 2000 TE，幕府与海祇岛的《和解备忘录》签署于 2025 TE。

### ✈️ 提瓦特航空概况

- **文档**：[国际/提瓦特航空概况.md](./国际/提瓦特航空概况.md)
- **志飞系列客机**：志飞联合制造集团公司占据全球商用飞机存量市场约 85% 和增量市场约 95%。产品线覆盖从 12 座通勤机（ZF-24）到 290 座宽体客机（ZF-48）的完整谱系，其中 **ZF-36** （约 867 架在役）为绝对主力机型。
- **航线网络**：全球商用机队总规模约 2,000 架，以璃月港国际机场为最大枢纽，连接七国主要城市。

### 💰 提瓦特金融体系概况

- **文档**：[国际/提瓦特金融体系概况.md](./国际/提瓦特金融体系概况.md)
- **摩拉的黄金时代**：岩王帝君摩拉克斯亲手铸造的摩拉兼具流通货币与元素反应媒介的双重功能，在长达数千年的历史中是提瓦特大陆唯一的国际通货。
- **帝君退位与通缩危机**：2000 TE 摩拉永久停铸后，存量摩拉在日益增长的贸易规模面前逐年通缩——至 2025 TE，物价指数已从基准 100 上升至约 180。各国被迫陆续发行主权信用货币，催生了多元货币并立的格局。
- **当前货币版图**：摩拉转型为国际储备资产与大宗商品结算核心媒介；七国各自发行主权信用货币（璃月元 MCY、至冬卢布 SNR 等），汇率浮动与货币主权成为地缘政治的核心议题之一。

### 🏭 提瓦特现代产业体系

- **文档**：[国际/提瓦特现代产业体系.md](./国际/提瓦特现代产业体系.md)
- **全球化产业链协同**：七国形成了高度互补的产业分工网络。
- **能源与算力底座**：蒙德输出风电、须弥沙漠输出光伏、纳塔输出地热、稻妻/踏鞴砂提供储能电池、须弥城提供算力、挪德卡莱提供水电
- **制造与硬件循环**：璃月提供基础材料与重工、稻妻提供精密电子、枫丹提供高端装备、至冬提供特种重工
- **服务与消费**：璃月港为贸易金融中心、枫丹廷为法律与时尚之都、蒙德为文旅休闲胜地、纳塔为体育康养之国

### 🌐 提瓦特虚空概况

- **文档**：[国际/提瓦特虚空概况.md](./国际/提瓦特虚空概况.md)

- **地缘政治影响**：各国通过国家网关按各自安全等级管理数据流动，璃月、须弥、枫丹为一级枢纽，构成提瓦特数字经济的三大支柱。

## 七国详览

### ⚜️ 蒙德

**国名**：蒙德自由合众国（Mondstadt Free Commonwealth）
**政体**：议会民主联邦制 | **首都**：蒙德城

#### 政治体制

蒙德是提瓦特西北部高度发达的民主联邦制国家。权力核心为联邦议会，由无政府主义者—自由工人联盟、保守党、自由民主党、绿党四大政党角逐席位。三级行政区划（领—市/区/军分区—乡/镇/警备区）构成治理骨架，其中「军分区」层级体现了蒙德对边境防御与冒险家管理的制度化安排。

#### 经济体系

- **清洁能源**：星落平原巨型风电群是提瓦特最主要的绿电输出地，风能技术世界领先
- **酿酒与饮料工业**：蒲公英酒业联盟的瓶装酒畅销全大陆，「天使的馈赠」为提瓦特最具辨识度的酒类品牌
- **生态农牧业**：大规模机械化种植与现代化牧场，提供优质的乳制品、小麦和农副产品
- **低空经济**：滑翔翼运动与热气球观光，民用转化自西风骑士团「风之翼」滑翔翼特种部队技术
- **铁路**：[蒙德铁路概况.md](./蒙德/蒙德铁路概况.md) 主干线由璃蒙铁路公司（LMRC）统营，MR 160 J 动力集中式动车组最高运行速度 200 km/h

### 🪨 璃月

**国名**：璃月共和国（Liyue Republic）
**政体**：新民主主义议会共和制（一党执政、多党参政） | **首都**：璃月港

#### 政治体制

「送仙典仪」后璃月步入人治时代，在原玉衡星刻晴与原天权星凝光的推动下，从七星寡头议政转型为新民主主义共和国。**璃月人民党**一党主导，共和党、自由党、农会联盟、民主党四党参政。众议院（约 1,200 人，按人口比例直选）为国家最高权力机关，参议院（约 150 人，由众议院选举产生）为常设立法机关。监察院独立于行政体系，直接由众议院选举产生院长，负责监督全体公职人员的廉洁履职。

#### 经济体系

- **国际金融与贸易**：璃月港是提瓦特最繁忙的深水港，璃月中央银行发行主权货币璃月元（MCY，1 摩拉 ≈ 0.85 璃月元）
- **重工制造**：层岩巨渊统筹开采集团掌控最大综合性矿产基地，璃月机车集团总装重型工程机械与商用车辆
- **铁路**：[璃月铁路概况.md](./璃月/璃月铁路概况.md) 璃月铁路总公司（LRC）运营，LR 系列动车组最高运行速度 240 km/h（预留 320 km/h），归离原—晨曦酒庄跨境连接蒙德
- **能源大讨论**：[三十年论战](./璃月/三十年论战：璃月能源路线大讨论与全民抉择.md) 以能源政策之争为主线，深入展现国家转型期的思想碰撞与民主决策过程

### ⚡ 稻妻

**国名**：稻妻群岛（Inazuma Archipelago）
**政体**：三大政治实体并存——幕府君主立宪、海祇岛议会共和、清籁岛人民民主专政 | **首府**：稻妻城

#### 政治格局

稻妻群岛呈现出提瓦特大陆最为复杂的政治格局——三股截然不同的政治实体在同一片群岛之上并存：

1. **幕府**（君主立宪制）：稻妻名义上的中央政权，在锁国传统与开放浪潮之间寻找平衡。雷神雷电将军为虚位元首，内阁对议会负责。经济以**半导体与集成电路**（雷元素微雕刻蚀技术）、**消费电子终端**（智能留影机、通讯设备）、**文化出版与动漫游戏**（八重堂 IP 产业链）为三大支柱。
2. **海祇岛自治领**（议会制共和政体）：通过《稻妻群岛与海祇岛和解备忘录》确立的自治领地位。独特的经济结构以**海洋生物制药**（珊瑚真珠深海药物）、**现代海洋产业**（深海养殖、海藻化工）和**高附加值农业**（鸣草改良经济作物）为特色。
3. **清籁岛**（社会主义人民民主专政）：工农革命党领导的计划经济，以铁矿、竹制品、制茶和药材加工为四大支柱。清籁岛的存在是稻妻战争遗留问题的结构性产物，也是群岛政治光谱上最鲜明的一极。

### 📚 须弥

**国名**：须弥社会主义联邦（Sumeru Socialist Federation）
**政体**：社会主义联邦制——两党共同专政 | **首都**：须弥城

#### 政治体制

须弥横跨东部雨林与西部沙漠，由纳西妲主义的劳动革命党与红色科学家联盟两党共同专政。旧教令院被拆分为三所顶层科研机构与四所部属高校，实现治学、工程、行政三权分离。三级行政区划（邦/直辖市—市/县—乡/镇）与基层群众自治相结合。

#### 经济体系

须弥经济形成独特的**双引擎格局**：

- **雨林区**：以高等教育与 AI 科研为核心，四所部属高校涵盖研究型（须弥科技大学）、应用型（须弥民众大学）、综合型（民族团结大学）和职业型（须弥职业大学）四大方向；虚空系统的民用化为各国提供 AI 算法与云计算服务
- **沙漠区**：列柱沙原超大型太阳能光伏电站群为提瓦特规模最大的集中式光伏基地，沙漠绿色算力中心利用极端日照与夜间低温降低能耗

### ⚖️ 枫丹

**国名**：枫丹重建共和国（Fontaine Restored Republic）
**政体**：贵族共和制 | **首都**：枫丹廷

#### 政治体制

枫丹实行独特的贵族共和制。元老院与平民院形成权力制衡，贵族分为五等——公、侯、伯、子、男——每一等级对应不同的政治权利与义务。治理特色在于**基层治理外包**：不设统一的基层行政组织，而是将职能委托给家族领地管理机构、行业协会或刺玫会支部。欧庇克莱歌剧院作为最高评议会所在地，同时也是枫丹法律服务体系的精神象征。

#### 经济体系

枫丹经济以四大支柱闻名：
1. **高端精密机械与机器人**：发条机关民用化与自动化产线，枫丹工程院领导技术研发
2. **法律仲裁与知识产权服务**：为提瓦特各国提供跨国仲裁和知识产权保护
3. **时尚奢侈品与美妆**：黎翡大区香水与枫丹廷时装沙龙引领提瓦特衣着风尚
4. **影视娱乐工业**：《蒸汽鸟日报》等传媒集团与枫丹映影工作室构成提瓦特最发达的影视制作体系

### 🔥 纳塔

**国名**：纳塔联盟（Natlan Federation）
**政体**：六共和国组成的超国家联合体 | **首府**：圣火市

#### 政治体制

纳塔联盟位于提瓦特西南部，由六个共和国——**回声之子、流泉之众、悬木人、花羽会、沃陆之邦、烟谜主**——组成的超国家联合体。六共和国各自拥有独特的政治体制（酋长议会制、贤者会议制、体育议会制等），将外交、国防、货币发行与古名信仰管理让渡于联盟。《圣火盟约》为宪法基础，联盟总统由全民直选产生，任期六年。

#### 核心特色

- **古名信仰**：[古名与还魂诗](./纳塔/古名与还魂诗——纳塔传统信仰体系.md) 深入剖析了这一古老灵魂信仰的哲学根基——「古名」是纳塔人死后留在世上的精神印记，还魂诗则是召唤古名回归的祭祀仪式
- **经济**：地热能源开发、极限体育与电竞产业、燃素相关特种新材料、温泉康养旅游
- **燃素城际线路**：沿高铁线位敷设燃素管廊，实现「能源网+信息网+交通网」三网融合
- **游隙灵道系统**：基于燃素流动形成的空中能量通路，城市间列车磁导向悬浮行驶，最高速度可达 180 km/h
- **铁路**：[纳塔铁路概况.md](./纳塔/纳塔铁路概况.md) 纳塔铁路联盟（NRU）统一管理高铁，NR 系列动车组最高运行速度 210 km/h

### ❄️ 至冬

**国名**：至冬国（Snezhnaya）
**政体**：高度集权的冻土工业帝国 | **首都**：至冬宫

#### 经济体系

严酷的冻土环境催生了至冬独特的四大经济支柱：

- **军工与航空航天**：提瓦特技术最完备的重型武器制造体系与极地航天发射能力，极地发射场具备独特的轨道入轨优势
- **化石能源开采**：冻土带下蕴藏提瓦特最大规模的油气储量，跨境管道向蒙德和璃月出口天然气
- **极地科考与破冰船制造**：全球领先的极地科考能力，核动力破冰船设计与建造工艺世界一流
- **全球冷链物流**：依托极寒自然条件和先进的冷链技术，冷冻食品出口覆盖提瓦特各国市场

#### 金融体系

- **至冬卢布**（SNR，1 摩拉 ≈ 0.5 至冬卢布）：至冬全境法定货币
- **北国银行**：专司跨境结算与国际金融服务，深度参与各国基建投资与产业并购，与至冬中央银行形成市场分立格局

### 🏔️ 挪德卡莱

**地区**：挪德卡莱（Nod-Krai，至冬国自治领地）
**政体**：11 股势力割据的**联合政府** | **核心首府**：那夏镇

#### 政治生态

挪德卡莱是至冬国南端面积广阔、至冬仅保留领土诉求的化外之地。这里没有狭义上的中央政府——**挪德卡莱联合政府**由 11 股势力平等组建，是实际上的最高权力机关，管辖范围覆盖以那夏镇为中心的统辖区域（约 1,360 km²）。出了统辖区域，便是各方势力割据的控制区与不承认任何政府权威的无政府地带。

#### 核心资源：月矩力（涅法海姆）

月矩力是三位月神陨落后残留在大地上的古老神力，也是挪德卡莱一切争端的根源。它是七元素的原始形态，能量密度为元素结晶的 15 倍以上，对深渊能量具有天然中和作用。低纯度矿石市场价约 500~1,000 SNR/kg，高纯度凝晶可达 50,000~150,000 SNR/kg。

#### 经济体系

挪德卡莱的经济是月矩力开采、贸易、自给农业与掠夺经济的混合体。伏尼契商会实际主宰经济命脉——秘闻馆同时扮演中央银行、情报交易所和地下金融中心的角色。年经济总量约 310 亿至冬卢布，人均 GDP 约 12,000 SNR（统辖区域人均约 60,000 SNR）。

农业自给率约 90%，由霜月之子的绿色畜牧业（银月奶酪、极地绿色牧产）与执灯士的屯田体系（寒地黑麦、温室种植）构成双层产出结构。

## 政权关系与地缘政治

### 稻妻战争与和平

幕府与海祇岛之间的战争是提瓦特当代史上最重要的地缘政治事件之一。**《稻妻群岛与海祇岛和解备忘录》**确立了停火与非军事区划定、海祇岛自治领的地位分野，以及双方在主权承认问题上的妥协方案。

**《稻妻战争的双面镜像：从大蛇东征到海祇岛和解的政治悲剧与和平探索》**以双重叙事结构深入剖析了这一冲突：从大蛇东征的神话起源到现代政治博弈，从幕府的锁国立场到海祇岛的自决诉求，揭示了超越善恶二元论的政治悲剧复杂性。该文档是理解稻妻群岛当代政治格局的核心文本。

### 货币主权与国际秩序

摩拉在帝君退位后的停铸引发了提瓦特金融体系的根本性变革：

- 各国脱离摩拉本位制，陆续发行主权信用货币；至冬卢布、璃月元等货币的出现标志着「后摩拉时代」的到来
- 摩拉从唯一国际通货转型为国际储备资产与大宗商品结算的锚定媒介
- 汇率浮动与货币主权成为地缘政治博弈的核心议题——各国央行在合作与竞争之间寻找平衡
- 北国银行（至冬）与璃月中央银行分别代表了「国有资本输出」和「贸易金融枢纽」两种不同的金融国际化路径

### 挪德卡莱——提瓦特的「巴尔干」

挪德卡莱的独特地位使其成为提瓦特地缘政治中最复杂的热点：

- **名义上**：至冬宣示主权，称其为「自古以来不可分割的自治领土」
- **实际上**：至冬控制力仅限于愚人众驻地和月矩力实验设计局，联合政府由 11 股势力平等组建
- **国际承认**：其他国家私下将联合政府视作挪德卡莱的国家政府，但官方层面沿袭至冬的「自治领地」说辞
- **核心矛盾**：月矩力资源的争夺与各方势力在联合政府框架内外的博弈

### 璃月能源路线之争

璃月内部关于能源发展路线的三十年大讨论（**《三十年论战》**）是理解璃月当代政治民主决策过程的窗口。争论焦点围绕：是依托传统符箓与元素动力技术走自主创新路线，还是引入至冬或枫丹的成熟技术体系加速工业化。这场大讨论最终以「技术自主优先、多元能源并进」的共识告一段落，深刻影响了璃月铁路电气化、汽车动力路线和重工业布局。

## 配套工具

本仓库提供以下 Python 辅助工具，位于 [`tools/`](./tools) 目录下：

### `fix_punctuation.py` — 文本规范化工具

对仓库中所有 Markdown 文件执行统一的标点符号与格式规范化处理，保障各区域文档的书写风格一致。具体操作包括：

| 功能 | 说明 | 示例 |
|-----|------|------|
| **中文引号替换** | 英文单双引号 → 中文引号（「」「『』」） | `"背景"` → `「背景」` |
| **数字间连字符** | 数字之间的 `-` 统一为 `~` | `45%-50%` → `45%~50%` |
| **数字/中文/英文间距** | 数字与非数字、中文与英文间补足/规整空格 | `郡GDP` → `郡 GDP`，`GDP的` → `GDP 的` |
| **加粗标记空格** | `**` 内部紧贴内容，外部依相邻字符自动补空格 | `的**30%**` → `的 **30%**` |
| **标题序号删除** | 移除 `## 一、背景` 中的中文/数字序号 | `## 一、背景` → `## 背景` |
| **分隔线过滤** | 删除独立成行的 `---` 分隔线 | — |
| **空行压缩** | 连续多个空行合并为一个 | — |
| **保护机制** | 代码块、行内代码、Markdown 链接/图片中的 URL 编码（`%2B`、`%20` 等）不受任何正则操作影响 | `[![Docs](...%2B-gray)](...)` 原样保留 |

工具的 `fix_bold_spacing()` 函数采用逐字符扫描算法，能正确区分 `**` 加粗标记的开闭位置，支持同一行内多次出现加粗、粗斜体（`***`）嵌套等复杂场景。`process_line()` 的执行顺序为：提取行内代码 → 提取 Markdown 链接占位符 → 执行全部字符替换与格式化 → 还原链接 → 还原行内代码 → 删除标题序号；这一流水线设计确保各步骤互不干扰。

**使用方式：**

```bash
cd tools && python fix_punctuation.py
```

工具会自动递归扫描仓库根目录下所有 `*.md` 文件（排除 `tools/`、`.git/`、`node_modules/` 等目录），输出处理统计信息（处理文件数、修改文件数、耗时、吞吐量）。

## 文档约定

### 货币说明块

各国家/地区的经济文档首行统一以 `> **货币说明**` 开头，格式如下：

```
> **货币说明**：[国家名][中央银行/发行机构]发行的**[币种名称]**（[币种代码]，[汇率说明]）为[使用范围]法定货币。[其他货币]仍作为国际储备资产继续流通。
```

### 数据表格风格

- 经济数据表格统一使用居中对齐（`:---:`）的 Markdown 表格
- 货币数据保留一位或两位有效小数，不精确至整数
- 大额数据使用「约」「估算」等限定词标注不确定性

### 文档命名规范

- 目录名统一使用国家/地区中文名称（如 `蒙德/`、`挪德卡莱/`）
- 文件名格式为 `[区域]政治概况.md`、`[区域]经济与产业概况.md`、`[区域]行政区划.md`
- 专题文档使用全称完整标题（如 `稻妻战争的双面镜像：从大蛇东征到海祇岛和解的政治悲剧与和平探索.md`）
