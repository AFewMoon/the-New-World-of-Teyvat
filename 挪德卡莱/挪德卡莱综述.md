# [挪德卡莱综述](挪德卡莱/挪德卡莱综述.md)

> **货币说明**：[至冬](挪德卡莱/至冬经济概况.md)中央银行发行的**[至冬](挪德卡莱/至冬经济概况.md)卢布**（SNR，1 摩拉 $\approx$ 0.5 [至冬](挪德卡莱/至冬经济概况.md)卢布）为[至冬](挪德卡莱/至冬经济概况.md)全境（含[挪德卡莱](挪德卡莱/挪德卡莱综述.md)）法定货币。在[挪德卡莱](挪德卡莱/挪德卡莱综述.md)那夏镇及主要聚居点，[至冬](挪德卡莱/至冬经济概况.md)卢布与摩拉均可使用；在[无政府地带](挪德卡莱/挪德卡莱行政区划.md)及偏远部落，实物交换仍占据主导地位。

## 国名与基本概况

**名称**：[挪德卡莱](挪德卡莱/挪德卡莱综述.md) (Nod-Krai)，[至冬](挪德卡莱/至冬经济概况.md)国南端群岛区域。

**实际[最高权力机关](须弥/须弥政治简明读本.md)**：[挪德卡莱联合政府](挪德卡莱/挪德卡莱政治概况.md)（各方势力平等组建，不称国家但运作方式与国家无异）。

**主要聚居点**：那夏镇（[联合政府统辖区域](挪德卡莱/挪德卡莱行政区划.md)中心）。

**面积**：群岛区域，伦波岛为最大岛屿。

**人口**：约 271 万（统辖区域约 190 万，其余高度分散于各岛）。

**官方语言**：提瓦特通用语、[至冬](挪德卡莱/至冬经济概况.md)语。

**货币**：[至冬](挪德卡莱/至冬经济概况.md)卢布 (SNR)，摩拉并行流通。

## 自然地理

[挪德卡莱](挪德卡莱/挪德卡莱综述.md)位于提瓦特大陆极北之地，北接[至冬](挪德卡莱/至冬经济概况.md)本土针叶林冻土带，南临无尽海。由多座岛屿构成岛链，自南向北依次为：伦波岛、[希汐岛](挪德卡莱/挪德卡莱行政区划.md)、设计局岛屿、[皮达米拉](挪德卡莱/挪德卡莱行政区划.md)地区所在岛屿。最北端为极北冻土边缘带，西北角有神秘的北境花园。区域地势由北向南逐渐降低。

| 地理单元 | 特征 |
|:--------|:-----|
| **伦波岛** | 最南端最大岛屿，人口最密集，联合政府统辖区域 |
| **希汐岛** | 西南岛屿，原始针叶林和冻原草甸，霜月之子领地 |
| **设计局岛屿** | 愚人众月矩力实验设计局军事禁区 |
| **皮达米拉地区** | 执灯人控制区，邻近狂猎活跃区 |
| **安瓦蒂尼尔湖** | 最大淡水湖，湖底蕴藏月矩力矿藏 |
| **极北冻土边缘带** | 狂猎最活跃区域，无政府地带 |
| **北境花园** | 最西北角，魔女会据点 |

## 历史概要

1. **[黄金国](挪德卡莱/挪德卡莱综述.md)的传说**：远古文明亥珀玻瑞亚拥有[月矩力](挪德卡莱/挪德卡莱经济与产业概况.md)技术，因触碰造物主领域而遭寒天之钉毁灭。
2. **[霜月之子](挪德卡莱/挪德卡莱综述.md)的迁徙**：幸存者在霜月女神引导下迁至[挪德卡莱](挪德卡莱/挪德卡莱综述.md)，回归原始生活方式。
3. **初代冰神与雪国妖精**：北陆统治时期，雪国妖精掌握[月矩力](挪德卡莱/挪德卡莱经济与产业概况.md)原始运用，构建古老遗迹。
4. **坎瑞亚灾变**：狂猎开始出现，深渊能量扩散留下深刻伤痕。执灯人组织壮大。
5. **[至冬](挪德卡莱/至冬经济概况.md)扩张**：[至冬](挪德卡莱/至冬经济概况.md)对[挪德卡莱](挪德卡莱/挪德卡莱综述.md)提出主权要求，但事实上区域保持独立。
6. **联合政府诞生**：猎月人雷利尔引发的狂猎风暴迫使各方组建临时联合指挥机构，事后正式制度化为联合政府。

## 政治体制

[挪德卡莱](挪德卡莱/挪德卡莱综述.md)没有狭义上的中央政府。[挪德卡莱联合政府](挪德卡莱/挪德卡莱政治概况.md)由各方势力平等组建，各在议事会中各有一票表决权。实际管辖权集中在伦波岛统辖区域。联合政府除不叫国家外，运作方式与国家无异。[至冬](挪德卡莱/至冬经济概况.md)以外的国家私下视其为[挪德卡莱](挪德卡莱/挪德卡莱综述.md)的国家政府。详见《[挪德卡莱政治概况](挪德卡莱/挪德卡莱政治概况.md)》。

## 行政区划

主要分为[联合政府统辖区域](挪德卡莱/挪德卡莱行政区划.md)、各势力割据区域和[无政府地带](挪德卡莱/挪德卡莱行政区划.md)。详见《[挪德卡莱行政区划](挪德卡莱/挪德卡莱行政区划.md)》。

## 经济

[挪德卡莱](挪德卡莱/挪德卡莱综述.md)[经济](挪德卡莱/挪德卡莱综述.md)以**[月矩力](挪德卡莱/挪德卡莱经济与产业概况.md)矿石开采与贸易**为支柱，其次为绿色畜牧业（[霜月之子](挪德卡莱/挪德卡莱综述.md)的驯鹿、山地山羊和极地兔畜产品）、农产品初加工和蒸汽工业。[伏尼契商会](挪德卡莱/挪德卡莱经济与产业概况.md)在[月矩力](挪德卡莱/挪德卡莱经济与产业概况.md)矿石贸易中发挥核心作用。主要进口精密机械、化工产品和日用消费品。详见《[挪德卡莱经济与产业概况](挪德卡莱/挪德卡莱经济与产业概况.md)》。

## 月矩力体系

[月矩力](挪德卡莱/挪德卡莱经济与产业概况.md)（古称「涅法海姆」）是一种独立于七元素体系之外的古老能量形式，是理解[挪德卡莱](挪德卡莱/挪德卡莱综述.md)一切纷争的核心概念。与七元素的关系类似于白光与七色光。月之轮是其与元素力之间的转换元件。[月矩力](挪德卡莱/挪德卡莱经济与产业概况.md)具有极强的能量密度，对深渊能量有天然的排斥和中和作用。当前应用包括蒸汽工业中的直接燃烧和通过月之轮的转换使用。

## 军事与国防

[挪德卡莱](挪德卡莱/挪德卡莱综述.md)不存在统一武装力量。各方势力拥有各自的武装：愚人众驻军（[至冬](挪德卡莱/至冬经济概况.md)军事/科研力量）、西风骑士团远征军（[蒙德](蒙德/蒙德综述.md)派出的深渊监控力量）、执灯人（古老的守护者组织，以月矩提灯对抗狂猎）、[霜月之子](挪德卡莱/挪德卡莱综述.md)自卫武装。狂猎本身即为天灾级存在。盗宝团和[冒险家协会](国际/多边关系/提瓦特国际组织概况.md)等组织也具备有限武装。

## 民生与社会保障

**教育**：有限的教育资源集中在[联合政府统辖区域](挪德卡莱/挪德卡莱行政区划.md)，偏远地带教育水平落后。**社会福利**：[联合政府统辖区域](挪德卡莱/挪德卡莱行政区划.md)内有基本的社会管理，[无政府地带](挪德卡莱/挪德卡莱行政区划.md)无正式[社会保障](须弥/须弥概况.md)。[霜月之子](挪德卡莱/挪德卡莱综述.md)内部有部落互助体系。**民族**：以[挪德卡莱](挪德卡莱/挪德卡莱综述.md)原住民（包括[霜月之子](挪德卡莱/挪德卡莱综述.md)、执灯人等）为主，另有[至冬](挪德卡莱/至冬经济概况.md)、[蒙德](蒙德/蒙德综述.md)等外来移民。

## 文化

[挪德卡莱](挪德卡莱/挪德卡莱综述.md)的宗教信仰与提瓦特七神体系截然不同，崇拜古老的**三月神**——霜月、空月、渊月。[霜月之子](挪德卡莱/挪德卡莱综述.md)保存着最完整的月神信仰体系，三月此消彼长构成独特的历法和祭祀周期。雪国妖精的血脉和传承至今仍影响着[挪德卡莱](挪德卡莱/挪德卡莱综述.md)的文化氛围。

## 对外关系

[挪德卡莱](挪德卡莱/挪德卡莱综述.md)在法理上属于[至冬](挪德卡莱/至冬经济概况.md)国「自治领土」，但事实上是独立政治实体。西风骑士团远征军在北部设有前沿哨站。伏尼契商会提供跨境金融结算与投资服务。[冒险家协会](国际/多边关系/提瓦特国际组织概况.md)在此设有重要分部。

## 挑战与展望

1. **多方势力的治理困境**：11 股势力交织博弈，联合政府实际管辖权有限。
2. **[月矩力](挪德卡莱/挪德卡莱经济与产业概况.md)开采与信仰冲突**：霜月之子视[月矩力](挪德卡莱/挪德卡莱经济与产业概况.md)开采为对月神的亵渎，与愚人众等势力根本对立。
3. **狂猎威胁**：作为持续存在的天灾级威胁，各方需在对抗狂猎上保持有限合作。
4. **经济基础薄弱**：除[月矩力](挪德卡莱/挪德卡莱经济与产业概况.md)矿石外，产业结构单一，高度依赖外部进口。
