# 挪德卡莱大事记

> 注:本文档中的「TE」(Teyvat Era) 为提瓦特纪年缩写，以 TE 为统一纪年单位，记录[挪德卡莱](挪德卡莱/挪德卡莱综述.md)从远古至今 (TE 2030) 的重大历史事件。[挪德卡莱](挪德卡莱/挪德卡莱综述.md)在法理上属[至冬](挪德卡莱/至冬经济概况.md)国「自治领土」，事实上为独立政治实体，直接沿用提瓦特纪元纪年。[至冬](挪德卡莱/至冬经济概况.md)相关历史事件以「（背景）」标注。

## 大事年表

| 年份 (TE) | 事件 |
|:---------:|:----|
| **远古** | **黄金国亥珀玻瑞亚**——掌握月矩力（古称「涅法海姆」）技术的远古文明，因触碰造物主领域而遭寒天之钉毁灭 |
| **远古** | **霜月之子的迁徙**——幸存者在霜月女神引导下迁至[挪德卡莱](挪德卡莱/挪德卡莱综述.md)，回归原始生活方式 |
| **初代冰神时代** | **雪国妖精**为北陆统治者，掌握月矩力原始运用，构建古老遗迹 |
| **约 1000~1200** | **（背景）** [至冬](挪德卡莱/至冬经济概况.md)逐步向南扩张，完成对极北族群的整合，将[挪德卡莱](挪德卡莱/挪德卡莱综述.md)纳入势力范围，主要采取册封地方首领、传教与贸易渗透的间接统治方式 |
| **1500** | **（背景） 坎瑞亚灾变**——深渊能量扩散留下深刻伤痕，**狂猎开始出现**；执灯人组织创立，先贤以古老月矩力知识创建专门对抗狂猎、保护平民的组织 |
| **1520** | **（背景） 愚人众执行官制组建**——至冬女皇以「执行官」为核心组建横跨七国的情报与军事组织 |
| **1600** | **（背景） 至冬科学院建立**，系统化研究坎瑞亚机关术与提瓦特元素反应 |
| **1800 年代** | **（背景） 月矩力价值发现**，[至冬](挪德卡莱/至冬经济概况.md)加强对[挪德卡莱](挪德卡莱/挪德卡莱综述.md)的控制，试图将化外之地纳入帝国行政体系 |
| **1960** | **（背景）** [至冬](挪德卡莱/至冬经济概况.md)石油天然气管道网络基本成型，辐射至冬全境及[挪德卡莱](挪德卡莱/挪德卡莱综述.md) |
| **2008** | **（背景） [至冬](挪德卡莱/至冬经济概况.md)卢布率先发行**，至冬中央银行成立，拉开信用货币时代序幕 |
| **约 2005~2010** | **猎月人雷利尔之灾**——堕落的坎瑞亚遗民雷利尔借助深渊之力掀起史无前例的狂猎风暴，城镇化为废墟，荒野沦为死地；霜月之子、执灯人、愚人众、伏尼契商会、盗宝团等平日相互敌视的势力被迫组建临时联合指挥机构，那夏镇成为各方力量协调中枢 |
| **猎月人灾变后** | **联合政府正式制度化**——雷利尔被剿灭后，各方认识到常设协调机构的必要性，临时联合组织转为[挪德卡莱联合政府](挪德卡莱/挪德卡莱政治概况.md)，各方在议事会中平等议事，逐渐不再诉诸武力解决分歧 |
| **2018** | **（背景）** [挪德卡莱](挪德卡莱/挪德卡莱综述.md)以联系成员身份加入提瓦特财团联盟 (TFC)——伏尼契商会承担事实上的货币兑换与调控职能 |
| **2022~2025** | **联合政府土地改革**——联合治安队组建「地改行动组」逐村推进，铲除地主中间层（处置大小地主约三百四十户），约 1,360 平方公里农田直接分给农户；农业税从约 1/10 升至 1/3，由治安队强制征收 |
| **2023** | **（背景） [挪德卡莱](挪德卡莱/挪德卡莱综述.md)数据自由港全面运营**，成为提瓦特数字经济中心 |
| **2025~2030** | **财税改革与行政膨胀**——营业税、消费税、关税与管制物品特种税相继开征，公债强制摊派实行；联合治安队从约 1,200 人扩编至约 7,200 人；抗税事件从地改后第一年约两百余起递减至每年三四十起 |
| **2030** | **当前**——11 股势力交织博弈，联合政府实际管辖权集中于伦波岛统辖区域（那夏镇及五镇）；狂猎仍为持续存在的天灾级威胁 |

## 展望

| 纪年 | 事件 |
|:----|:----|
| **中长期** | **狂猎威胁与月矩力枯竭**——月矩力不可再生，以目前开采速度估算浅层矿脉约可供开采 30~50 年；狂猎作为周期性天灾持续威胁 |
| **中长期** | **地改税负矛盾**——土地权利有保障但代价高昂，治安队强制征收手段使「发展」与「剥夺」的边界在乡村持续引发焦虑 |
